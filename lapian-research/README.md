# 《凡人修仙传》拉片研究（Lapian Research）

对 B 站 43 期《凡人修仙传》拉片视频做的结构化拆解与再整理：把「他讲了什么」变成可检索、可复用的镜头规则与案例库。

- **43 期**视频、**10 小时 21 分**正片，全部逐帧看完
- **42 份**分析报告（`视频分析报告/`）
- **43 份**文案记录（`文案记录/`）
- **336 张**连续帧抽帧图（`运镜帧序列/`，43 个场景）
- **558 条** IF-THEN 导演决策规则（`01_拍摄技巧总纲.md`）
- **118 个**案例的视听语法库（`05_拉片案例书.html`，单文件，浏览器直接打开）

## 附带的 60 秒介绍片

`video/lapian_shotcraft_60s_v2.mp4` · 59.16 s · 1920×1080 · H.264 + AAC

片中只讲作品本身的三个镜头手法：焦距＝追击决心刻度、运镜叠加＝情绪加压、越轴＝情绪「咯噔」；后半段介绍案例书怎么用。

- 制作方式：HTML/CSS 时间轴页面 → Playwright 逐帧渲染 → FFmpeg 合成；旁白为 edge-tts 合成语音，配乐由代码合成
- 画面素材：本目录内的静态抽帧图 + 用 Playwright 打开 `05_拉片案例书.html` 的实拍截屏
- 详细分镜、素材清单与占位说明见 `video/旁白与素材_v2.md`
