# Case Study 016 — 水岸独舞 · 双段连续（Waterfront Solo Dance · Two Segments）

> 一支 24.474 秒的古风当代独舞（BPM 100.0，beat 0.6000s），**经逐帧证实为单一连续锁定镜头**，按小节强拍切成 2 段（12.070s / 12.404s）分别生成再拼接。**PICTURE 1 锁人物/服装/外观（提示词零外貌描写）**，**分段 AUDIO 1 锁节拍网格**；编舞用**链记法**（入态→拍数→出态），段间以**动作接力**衔接（探海螺旋臂下拖 → 拖臂上提交叉穿掌）。本案例的核心产出是一条**单镜头验证流程**。

## Inputs（输入）

- **PICTURE 1**：唯一视觉权威——人物身份、脸、发型、体型、长裙与全部配饰；提示词零外貌描写。
- **AUDIO 1（分段提供）**：BPM 100.0、beat 0.6000s、bar 2.4000s、首拍 0.070s；320kbps MP3，切点落在小节强拍 12.070（k=5 downbeat）。
- **无视频参考**：动作经链库文字转写。
- 两段可直接粘贴的提示词全文：[`prompt.md`](./prompt.md)。

## The problem（踩过的坑）

1. **"单镜头"假设未经检测**：初看无剪辑点就当一镜到底——但 0.27 阈值探不到 ≠ 没有切点。降到 0.06 后命中 14.5s / 18.13s 两处，逐帧核对均为**逆光光晕掠过与大侧弧快速段**（运动触发），证伪切点、证实单镜头——验证流程本身成为本案例最有复用价值的产出；
2. **中段块序错位**：凭 1s 间隔初看排的"涮腰大弧 → 拧倾交替"，逐帧核对 local ~6.0s 实为**大侧弧**——两块对调后才与源片对齐；
3. **段间接力**：SEG01 结尾是"探海式平衡后向下螺旋、双臂拖低"，SEG02 开场必须从**同一动量线**接住（拖臂上提、交叉穿掌），而不是从站姿重启。

## The breakthrough（写死的事）

### 1. 单镜头验证流程（三步）

`0.27 全局切镜检测（无果）` → `0.06 低阈值复测（命中 2 处）` → `逐帧核对命中点（±0.2s，查位置跳变）` → 证伪为运动/光晕 → 单镜头成立。**低阈值命中≠切点**：快速动作与光源掠过都会触发，必须逐帧终审。

### 2. 小节线切块

beat 0.6000s / bar 2.4000s / 首拍 0.070s：全部块边界吸附小节线（0.000 / 2.470 / 4.870 / 7.270 / 9.670 / 12.070 / 14.470 / 16.870 / 19.270 / 21.670 / 24.404），每块整 4 拍，链的拍数写死。

### 3. 链记法 + 动作接力

每链【入态（承接上一链出态）→ 拍数分解 → 出态】；SUSTAINED LAYER（C1 呼吸引擎）每拍不断；SEG01 末链出态 = SEG02 首链入态（探海螺旋臂下拖 = 拖臂上提），切点在小节强拍上、动作跨切连续。

### 4. 舞蹈/非舞蹈音频分流（常设规则）

舞蹈/卡点类 → 切音频（AUDIO 1 随段提交，1:1 复用）；**小剧场/剧情类 → T2VA 不切音频**，对白与环境声按字幕表/事实重建（见 Case 015 系列后续）。

## 提交工作流

1. 每段独立生成：附 **PICTURE 1** + **AUDIO 1**（该段 mp3）；
2. 两段按切割时间轴（0.000 / 12.070）拼接，切点即动作接力点；
3. 全程锁定正机位，逆光光晕保持在头部后方。

## Anchor check（提交前逐条过）

- **anchor coverage**：双段齐备——单图锚、SUSTAINED LAYER、链记法（入态/拍数/出态）、段间接力句、锁定机位声明、终止信号（SEG02 终格 absolute stillness）；
- **continuity**：SEG01 末链出态 = SEG02 首链入态（探海螺旋臂下拖 = 拖臂上提），点名到部位与方向；
- **timing**：全部时间戳自首拍 0.070 复算并吸附小节线；段长与切点 12.070 精确一致；
- **physical causality**：动作链保持"脚→重心→胯→腰→肩→臂→腕"因果顺序，裙摆只跟随不独立发力；
- **anti-copy distance**：参考动作经链库文字转写，不附视频、不复用其人物/场景节奏。
