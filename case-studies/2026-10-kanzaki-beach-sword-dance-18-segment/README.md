# Case Study 023 — 神裂火织 · 晴日海滩剑舞音乐 MV 十八段（Kanzaki Sunny-Beach Sword-Dance MV · Eighteen Segments · 两项锁定修正版）

> 一支 230.034 秒、16:9 的**真人剑舞音乐 MV**，按歌曲切割点切成 **18 段独立可生成**（9 组、每组两段）的 H3 提示词。每段都是 self-contained：只喂**同一张参考图 `<Picture 1>` + 该段裁剪音频 `<Audio 1>`** 即可单独出片。`<Picture 1>` 是**人物 + 现场双重锁定**的唯一视觉权威（人物脸/长发/发带/白色打结短上衣/牛仔裤/棕色长靴/剑与刀鞘，以及蓝天、白云、海面、浅浪、湿润反光沙滩、自然日光）；动作与运镜只参考另一套剑舞抽帧的**动态剑路与摄影机语言**，绝不把小说里的敌人、魔法、水翼、特效搬进来。这是一支高完成度的 solo sword-performance MV，不是战斗剧情复刻，也不对口型。
>
> 本案例同时沉淀了一套面向真人音乐 MV 的中文导演方法论（11 章 + 两次自检），见 [`methodology.md`](./methodology.md)，重点是**参考图权限边界、道具外观/状态双规则、NO DEGREE LAW 物理机位、一镜到底与组间后期桥接**。

## Inputs（输入）

- **PICTURE 1（唯一视觉参考，同时锁人物 + 现场）**：人物身份与外观（脸、长发与发带、白色打结短上衣、牛仔裤、棕色长靴、剑与刀鞘的外观）**以及**海滩环境（蓝天、白云、深蓝海面、浅浪、湿润反光沙滩、自然日光）全部来自图 1；不重新描述图中已有外观，不引入图中没有的人物/道具/特效/地点。
- **AUDIO 1（每段一段，唯一时间/节奏/音乐权威）**：每段喂对应的裁剪音频（`seg01 … seg18`），**不要一次喂整曲**；音频 1:1 复制，不重启、不循环、不混音、不加第二首 BGM，不重切齐到小节。
- **动作/运镜参考（只借动态，不借画面）**：参考另一套《H3 反派 BOSS 剑舞｜密集抽帧精修版》的**剑路与摄影机语言**（低位起势、胸前横线、斜向拔斩、头顶圆弧、腰位回扫、深低位、宽弓步、旋身恢复、控刀护势）；不继承它的人物、场景与任何战斗元素。
- **无视频成片随仓分发**：真人成片、参考图、音频、封面均为本地文件，出于肖像 / 版权考量不公开。

## 音乐时间网格（manifest）

- **总时长 230.034 秒**（03:50.034）；**BPM 139.5**；单拍（beat）约 **0.4301 s**；小节（bar，4 拍）约 **1.7204 s**；乐句（phrase，2 小节 / 8 拍）约 **3.4409 s**。
- 共 **18 段，每段 10.574–13.793 s**，全部落在 10–15 s 区间；每段动作时间戳按段内 local time，重音 / 乐句作为动作峰值与镜头响应的共同锚点（1:1 同步）。
- 段 14、15 为器乐段（无歌词）；歌词只做节奏参考，不生成字幕、不做 lip-sync。

## 核心方法

### 1. 参考图权限：人物外观与场景权限必须分开声明

本案例（方案 A · 晴日海滩）图 1 **同时**是人物与现场的视觉依据，因此海滩、天光、海岸线全程继承，机位可换、地点不可换。与之对照的方案 B（浪漫奇幻）只让图 1 锁人物、明确允许背景替换为暮色海岸 / 石廊 / 灯盏。两种写法**不能混用**：要保留原背景就别写大段新环境，要换背景就别把图 1 的环境设为绝对权威。

### 2. 道具"外观规则 + 状态规则"双轨（本案例最硬的连续性约束）

- **外观规则**：剑与刀鞘长什么样，完全以图 1 为准，文字不重复描形状/结构/颜色，避免模型重绘、复制。
- **状态规则**：把武器在全曲的**状态时间表**写死并逐段复述——
  - **Segment 01–02**：只负责开场"从图 1 原刀鞘拔出刀身"；
  - **Segment 03–18**：每段第一帧**刀已在手中**，腰间只保留图 1 原位的**空刀鞘**，整段不再拔刀、不做拔刀式动作、不重新收刀；
  - 任何时刻只有**一把刀身 + 一个原刀鞘**，杜绝"手里有刀、腰间又挂完整刀身/刀柄"的复制错误。
- 图 1 的收刀初始画面只用于锁定外观，**不得覆盖当前段落的时间状态**；每段独立提示词必须显式覆盖与图 1 初始状态冲突的当前状态。
- 握持统一用**解剖学左右手**，不用"画面左/右边"这种会随朝向产生歧义的描述。

### 3. 每段一镜到底 `[Shot 1]`，组间连接交给后期

段内不硬切、不闪白、不做速度坡度、不反复变焦、不生成分屏；所有变化由真实摄影机运动（推拉 / 横移 / 跟拍 / 摇摄 / 轻微环绕 / 升降 / 自然焦点转换）完成。两组两段**不强制首尾帧逐帧一致**，组间用剑身反射、湿沙倒影、发丝掠镜、海平线、运动模糊等做后期匹配剪辑。

### 4. NO DEGREE LAW：用物理关系代替角度数字

不写"orbit 35° / 俯拍 20° / Dutch 5°"，改写**起始机位 → 物理移动路径 → 主体触发 → 结束机位与构图**（如 `the camera tracks from a front three-quarter position toward her side, following the torso rotation while keeping the full-body sword movement readable`）。规范从总则贯彻到每一个镜头，不允许总则禁角度、分段却残留度数。

### 5. 每段一个主运镜 + 至多一个辅助运动；景别服从当拍动作

避免 18 段全在环绕/横移/升降的重复语法。每段先定主运镜，再按需加一个辅助运动。景别是优先级问题：完整剑路优先全身与轨迹，情绪与眼神用中近景，拔刀/收刀/控刀优先让手部与道具可辨认——不把脸、双脚、道具轨迹、远景塞进同一镜头。

### 6. 动作写成时间中的过程，动作链必须完整

剑舞不是连续挥道具。每个动作写清**蓄势 → 重心启动 → 扩张 → 强拍峰值 → 制动 → 恢复 → 下一动作**，由"脚步 → 重心 → 髋/躯干 → 肩 → 腕 → 剑尖"形成完整动力链，旋身由脚步与髋部带动；节奏有停顿疏密，不每拍机械挥刀。全身比例自然，抬后腿不超髋部，不做无准备高踢、翻滚或空中悬停。

### 7. 每段只解决一个主要视觉问题 + 9 组能量曲线

建立 → 蓄势 → 展开 → 情绪留白 → 再推进 → 高潮 → 英雄式收束：前段亮相建场，中段加低位/连续剑路/旋身与力度，08–09 组升级到器乐高潮与最终高潮，第 18 段拉远成干净、可记忆的海岸英雄定格。相同结构不代表每段套用同一动作/镜头模板。

### 8. 背景连续性单独管理 + 声音身份锁定

固定场景方案：镜头改变观察位置，环境本身始终继承，海岸线 / 海平面 / 阳光方向不跳变。Audio 1 是唯一音乐权威；海浪、脚步、衣料、刀刃声压在低音量做环境，**不加第二首音乐、不加对白、不加战斗呼喝、不对口型、不做歌词演绎**。

### 9. 每段 self-contained 六字段

每段重复包含 `subject_definitions / summary / retention_analysis / detailed_description / overall_soundscape / non_diegetic_music`，把本段必需的身份、环境、道具状态、音频与镜头规则全部内联；不依赖模型记住上一段，也不把决定成败的规则只放在通用说明里。

## 两次自检（提交前）

- **技术与连续性**：人物身份与图 1 权限是否明确；每段音频是否准确、动作有无超出时长；刀身/刀鞘状态是否与全曲时间表冲突（尤其 Seg03 起刀已在手）；场景规则是否互相打架；镜头是否可执行、有无残留角度数字；负面约束是否堆积、有无压制正常眼神表情。
- **作品级五问**：这一段有没有记得住的动作？和前一段视觉重点是否真不同？摄影机为何在这里接近/后退/横移/转向？看完是否想继续看下一段？最后一镜结束时观众感到的是"一支 MV 完成了"还是"视频停止了"？

## 最值得迁移的几条

1. **外观锁定与状态锁定分离**：外观交给图，状态交给全曲时间表；分段独立生成时，用文字覆盖"当前状态"而不是重复画外观。
2. **道具状态机写到每段**：拔刀/持刀/空鞘/收刀给出明确区间，数量守恒（一把刀身 + 一个鞘），解剖学左右手统一。
3. **物理机位 + 单主运镜**：NO DEGREE LAW，每段一个主运镜、景别服从动作，从总则到每镜头一致。
4. **一镜到底 + 后期桥接**：段内用真实运镜，组间用反光/转身/发丝/海面做匹配剪辑，不强求首尾帧一致。
5. **纯表演 MV 的声音纪律**：Audio 1 唯一权威，无对白、无口型、无第二首音乐，环境声只做底。
