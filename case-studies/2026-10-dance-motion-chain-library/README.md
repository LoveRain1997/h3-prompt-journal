## 核心纪律速览

1. **三层结构写进每段提示词**:持续层(全段恒定:宅舞=内八膝弹跳;抖舞=胯八字;古风=提沉呼吸) + 动链层(逐拍) + 微表情层(反拍的头/眼/手指)。
2. **对接**:上一链的出态 = 下一链的入态。
3. **旋转预算**:整支舞 ≤2 次;静止必须明写,否则模型匀速化。
4. **动作链十要素**:每条链必须写全 `动作状态 → 受力来源 → 进入路径 → 逐拍动力变化 → 技术峰值 → 惯性延续 → 回收顺序 → 身体/服装物理 → 镜头几何 → 音乐触发`——禁止退化成"动作名+形容词"。
5. **摄影机双系统**:视角按 I 章(机位=物理实物+位置+几何+防简化),运镜按 E 章+物理运镜十法则(每段一个主运镜行为,镜头只为重大空间变化而动)。
6. **动作×运镜 1:1 同步(最高优先级经验)**:一套时间码、两条同步运动轨迹、同一组动作峰值——onset 时间戳同时是身体峰值时间戳与相机响应时间戳。
7. **时间窗动作链完整性(TIME-WINDOW ACTION-CHAIN INTEGRITY,强制前置检查)**:先确定时间窗能完成什么动作,再安排细节/重拍/运镜——禁止先堆高级动作再硬塞进过短窗口。容量参考:0.3-0.6s=一个短促重拍;0.6-1.2s=一条完整短链;1.2-2.5s=一条复合舞句;更长=复杂舞句或分阶段 Hero。抱臂反复摇晃/原地抖动=窗口过载失败信号,不能靠加"高级/Hero"形容词修复。失败诊断四情况与逐窗验收十项见库文件「0. 使用规则」第 9 条。

## 如何使用本库

1. **拼一支舞**:按"拼舞模板"选弧线(建立→发展→扩展→高光→呼吸→收束),填 bar 表,写出入态对接句。
2. **取单链**:每条链的 `- H3:` 行就是可直接粘贴的英文动作描述,替换主语/道具即可跨项目复用。
3. **取范本**:H 章 13 支是整段可粘贴的成品;J 章 9 支是写真式成品;K 章 518 条按片分组的扩展动链包(含背景人物档案,可直接抄场景+人物+链三件套;batch5 的 14 片全文见报告库 D002-D015);I/E 章是摄影机语言标准(另见本仓库 [System A](../2026-10-physical-camera-position-library/) 与 [System B](../2026-10-camera-movement-discipline-library/) 案例的独立整理版)。
4. **库的实战样板**:案例 [025](../2026-10-baifeng-mengchen-classical-dance-six-segment/) 用 C16/C17/C24/C28 等标准件重编六段古风舞;案例 [028](../2026-11-yueyoukui-in-place-guofeng-dance-mv-17-segment/) 用 C1/C2/C3/C5/C7/C12/C16 + Hero 族直编十七段原地古风 MV——两例都演示"库链 → 无道具/原地改造 → 入出态对接"的完整流程。
