## 一、这套方法能做出什么

只用**一张同时包含两位主角的定妆图**和**一整首歌（含逐句歌词时间轴）**，就能稳定产出一支多段、可逐段生成的双人对口型 MV：



* 人物身份、服装由唯一一张定妆图锁定，跨段不漂移、不换脸、不串造型；

* 音乐被切成 10–15 秒、**绝不切断唱句**的分段，每段一条独立可复制的提示词；

* 只在导演选定的关键句启用可见对口型，其余歌词仍在原音轨播放、画面不做逐字口型；

* 动作、运镜、剪辑全部吸附在音乐时间轴上，段间姿态与空间连续。

> 核心认知：H3 提示词工程的难点不在调参数，而在
>
> **教会模型一种关于 "转场与连续性" 的物理逻辑**
>
> —— 人物从不消失、动作跨段续接、切点吸附在音乐事件上。
>
> **音乐时间轴是稳定性的根基。**

## 四、整体流程总览



```
一张双人定妆图 ─┐
                ├─→ ① 人物锚定（Picture 1 只锁人物）
整首歌 mp3 ─────┼─→ ② 分析 BPM / 节拍网格
逐句 SRT ───────┼─→ ③ 歌词感知切割（不切词，10–15s）
                ├─→ ④ 生成 cuts_manifest.json + 切片
                ├─→ ⑤ 注入 Female / Male / Duet 人声标记
                ├─→ ⑥ 选定可见唱口（对口型）窗口
                ├─→ ⑦ 按六字段写每段独立提示词
                └─→ ⑧ 逐段生成 → 验收 → 拼接成片
```

## 五、分步操作

### Step 1・准备一张双人定妆图

选一张同时包含两位主角、服装清晰的合照。它是**全片唯一的人物身份与服装参考**，但不负责场景、姿势、构图与光线 —— 背景可按每段剧情自由重绘。

### Step 2・准备逐句歌词 SRT

标准 SubRip 格式 `HH:MM:SS,mmm --> HH:MM:SS,mmm`。若 SRT 中混入文本为 `[Duet]` 之类的标记条目（非真实唱句），在后处理时移除，只保留真实唱句。

### Step 3・分析 BPM 与节拍网格



```
python scripts/analyze_audio.py "song.mp3" --out analysis.json
```

输出 BPM 候选（含半速 / 加倍）、选定 BPM、首拍、beat/bar/phrase 间隔与低能量区间。慢板 / 古风常把正确速度报成 "半速"，需结合候选峰人工锁定。

### Step 4・先看方案，确认零切词



```
python scripts/cut_by_lyrics.py --audio "song.mp3" --srt "song.srt" `
    --outdir out --analysis analysis.json --plan
```

`--plan` 只打印切点、段长、每段歌词与切词检查。确认 "进入唱词的切点 = 0、唱句完整" 后再实切。

### Step 5・实切，生成 manifest 与切片



```
python scripts/cut_by_lyrics.py --audio "song.mp3" --srt "song.srt" `
    --outdir out --analysis analysis.json
```

切完脚本自动用 ffprobe 独立自检（实测段长、求和、逐句完整、无切词）。

### Step 6・注入人声标记

按 SRT 条目顺序，逐句映射 `vocal`（Female / Male / Duet），有风格词的另写 `vocal_style`；每段汇总 `vocals`，`meta` 写入 `vocal_legend` 与 `vocal_counts`。本例真实统计：



```
Female 43 · Male 24 · Duet 1 · 真实唱句合计 68
```

### Step 7・选定可见唱口并写段提示词

依据 `vocal` 标签挑选关键句做可见对口型（本例 24 个窗口），按 Full-Reference Mode 六字段输出每段独立、可单独复制的提示词。

## 六、切割产物 `cuts_manifest.json` 字段详解

该文件是连接 "音乐分析" 与 "视频提示词" 的唯一事实源，分顶层 `meta` 与 `segments` 两部分。

### 6.1 顶层 `meta` 字段



| 字段                    | 类型     | 含义                                          |
| --------------------- | ------ | ------------------------------------------- |
| `source`              | string | 源音频文件名                                      |
| `srt`                 | string | 歌词字幕文件名                                     |
| `bpm`                 | number | 每分钟节拍数（本例 147.5）                            |
| `beat_sec`            | number | 单拍时长（秒）                                     |
| `bar_sec`             | number | 一个小节（4 拍）时长                                 |
| `phrase_sec`          | number | 一个乐句（8 拍 / 2 小节）时长                          |
| `first_downbeat_sec`  | number | 首拍时间（秒）                                     |
| `min_sec` / `max_sec` | number | 分段允许的最短 / 最长时长                              |
| `target_sec`          | number | 分段目标时长（默认 12.5）                             |
| `total_duration`      | number | 全曲总时长                                       |
| `segment_count`       | number | 分段总数（本例 17）                                 |
| `accent_legend`       | object | 节拍重音四级（phrase/downbeat/onbeat/offbeat）的文字说明 |
| `note`                | string | `local` 与 `global` 时间的使用说明                  |
| `vocal_legend`        | object | 人声图例：Female / Male / Duet                   |
| `vocal_counts`        | object | 人声计数（本例 Female 43 / Male 24 / Duet 1）       |
| `sung_line_count`     | number | 真实唱句数（本例 68）                                |
| `vocal_note`          | string | 人声处理说明（如移除标记条目、风格词规则）                       |

### 6.2 `segments[]` 每个分段字段



| 字段             | 类型             | 含义                              |
| -------------- | -------------- | ------------------------------- |
| `seg`          | number         | 段号（从 1 开始）                      |
| `start`        | number         | 该段在原曲的全局起点（秒）                   |
| `end`          | number         | 该段在原曲的全局终点（秒）                   |
| `length`       | number         | 段时长（秒）                          |
| `cut`          | bool           | 是否为硬切边界                         |
| `file`         | string         | 对应音频切片文件名                       |
| `lyrics`       | array\[string] | 该段包含的唱词文本                       |
| `lyric_events` | array\[object] | 逐句字位与人声标记，见 6.3                 |
| `beats`        | array\[object] | 段内节拍点，见 6.4                     |
| `vocals`       | array\[string] | 该段人声去重汇总（如 `["Female","Male"]`） |

### 6.3 `lyric_events[]` 子字段（逐句字位）



| 字段                            | 含义                                                  |
| ----------------------------- | --------------------------------------------------- |
| `text`                        | 该句歌词文本                                              |
| `local_start` / `local_end`   | 相对**段头**的起止秒（H3 段内时间轴直接使用）                          |
| `global_start` / `global_end` | 相对**全曲**的起止秒                                        |
| `vocal`                       | 该句人声：`Female` / `Male` / `Duet`                     |
| `vocal_style`                 | 可选，演唱风格词（如 `Playful, Bright, Chinese Folk Singing`） |

### 6.4 `beats[]` 子字段（节拍卡点）



| 字段       | 含义                                                            |
| -------- | ------------------------------------------------------------- |
| `local`  | 相对段头的节拍时间（秒）                                                  |
| `global` | 相对全曲的节拍时间（秒）                                                  |
| `k`      | 节拍序号                                                          |
| `accent` | 重音级别：`phrase`（k%8）/ `downbeat`（k%4）/ `onbeat`（k%2）/ `offbeat` |

> 注意：
>
> `beats`
>
>  是按 BPM 推算的
>
> **等间隔理论网格**
>
> ，用于段内卡点；真实鼓点需经分轨 onset 检测另行反推，不能凭网格编造。

### 6.5 片段示例



```
{
  "seg": 1,
  "start": 0,
  "end": 12.261,
  "length": 12.261,
  "file": "seg01_00m00p00s-00m12p26s.mp3",
  "lyrics": ["哀 靓仔靓仔我爱你嘢，哀挨矮爱挨"],
  "lyric_events": [
    {
      "text": "哀 靓仔靓仔我爱你嘢，哀挨矮爱挨",
      "local_start": 6.958,
      "local_end": 11.541,
      "global_start": 6.958,
      "global_end": 11.541,
      "vocal": "Female",
      "vocal_style": "Playful, Bright, Chinese Folk Singing"
    }
  ],
  "beats": [
    { "local": 0.046, "global": 0.046, "k": 0, "accent": "phrase" }
  ],
  "vocals": ["Female"]
}
```

## 七、人物锚定与 Subject / Speaker 映射

`<Picture 1>` 是双人合照，只锁人物，不锁场景：



* 固定两位主角的面部身份、五官比例、发型、身形及服装主轮廓与色块；

* 两人的脸、发型、身形、衣装不得互换、融合、复制或漂移；

* 不擅自增减外套、披风、盔甲、武器，不改变服装配色与基本设计；

* 合照背景与站姿不复制，场景可按剧情自由重绘。

固定的 Subject / Speaker 映射（不随切镜或左右换位改变）：



| 画面主体   | 角色   | H3 Subject                    | Speaker ID | 声部                |
| ------ | ---- | ----------------------------- | ---------- | ----------------- |
| 紫白裙装女性 | 紫兰仙子 | `<Subject 1>`                 | `S1`       | Female Vocal only |
| 棕白服装男性 | 美猴王  | `<Subject 2>`                 | `S2`       | Male Vocal only   |
| 真实合唱窗口 | 两人   | `<Subject 1>` + `<Subject 2>` | `(S1,S2)`  | 仅真实 Duet          |

S1 永远是女声、S2 永远是男声，不创作额外说话声或替代歌声。

## 八、对口型（唱口）设计规则

### 8.1 选择性唱口，而非全程对嘴



* 全曲 68 个唱句，只挑关键句做**可见唱口**（本例 24 个窗口）；未选中的歌词仍在原音轨完整播放，画面人物不做逐字口型。

* 每个可见唱口事件直接写在实际发生的 `SHOT` 描述内部，每条 `<d>[Chinese]…</d>` 只出现一次，紧邻时间、Subject/Speaker、动作与镜头要求。

* 单人演唱时仅对应角色可见唱口，另一人自然闭唇，以目光、呼吸、重心与表情回应。

### 8.2 单人唱口单人可见



* Female 事件只让 S1 完成可见口型；Male 事件只让 S2 完成。

* 另一角色在该时间窗内不以清晰正脸 / 侧脸同时入画：优先完全出画，其次用背面、肩后轮廓或嘴部不可辨认的远层背景。

* 不能只写 "闭唇聆听" 却仍把两张脸并排放进唱口镜头。

### 8.3 唯一真实 Duet



* 仅 Segment 13 的局部窗口 `00:03.564–00:06.189` 允许两人同框、两张嘴同时同步。

* 相邻的独唱事件不扩展为双人唱口；Duet 不得拆成一人唱、另一人假唱。

### 8.4 唱口窗口与人脸构图



* 唱口镜头在歌词开始前先建立构图，完整覆盖事件；最后一个音节结束后自然闭唇再切，切点不放事件中间，下一角色不提前张嘴。

* 使用稳定中近景 / 近景，固定物理距离、焦段与构图；只允许轻微横移或微小平移，不做拉远、推近、快速变焦、绕脸环拍或突然改变景别。

* 需要空间尺度时，切到建筑、花海、月亮、云海、桥体、倒影、衣摆、手部或背影，不从脸部特写直接拉成远景再推回。

* 唱口镜头保证嘴唇、下颌、下巴清晰可读：不遮嘴、不大幅甩镜、不快速拉焦。

### 8.5 无唱口段落



* 第 03、07、11、16 段完全没有可见唱口；其中 Segment 16 为纯器乐视觉段，靠花树、月池、云台与双人舞句承载画面。

* 双人同框的非唱口镜头只承担关系、反应、动作与空间连续性，两人自然闭唇，不对画外人声模拟演唱。

## 九、统一视觉、摄影与剪辑标准



* **画幅：** 4:3 原生构图（本例 1280×960 规格）；不生成书法水印、印章、片名、歌词字幕或乱码。

* **写实质感：** 实景古装奇幻爱情剧质感，真实皮肤、毛发、布料、石材、水面；适度光晕柔焦，避免塑料皮肤、过度锐化与现代 CG 游戏感。

* **色彩分区：** 初遇暖绿粉紫 → 缘起青绿雨色 → 山头金绿 / 天宫金紫 → 花海高饱和粉紫 → 正殿金白 → 月下冷青紫 → 重逢紫金回暖 → 高潮暖红金 → 结尾明亮紫金。

* **镜头层次：** 每段组合环境全景、人物中景、近景、表情特写、空镜插镜、前景遮挡与匹配剪辑；不连续 12 秒只有一个远景，也不每段都从面部特写开始。

* **运镜描述：** 用实际摄影机高度、与人物距离、移动路径、前景遮挡与相对位置说明，不使用角度数字标签；优先贴身侧移、肩后切入、低位滑行、沿栏杆横移、短弧线跟拍、俯视揭示、前景擦镜、视线反打；不做无意义绕转、反复推拉或数码变焦。

* **音乐剪辑：** 以 3.254s 乐句安排镜头重心，但不机械每拍切一次，动作可跨强拍连续完成；唱口时间窗是强制表演边界。

* **空间连续性：** 同一场景的栏杆、柱子、树、湖面方向与人物左右关系稳定；场景切换由视线、色彩、形状、动作、前景遮挡或明确的回忆 / 平行蒙太奇完成，不做无动机瞬移。

* **走位克制：** 默认先移动摄影机与剪辑、不先移动人物；多数场景从人物已在合理位置开始。只有歌词确实要求追逐、同行、回头、奔赴、重逢时，才安排有明确起点、方向、终点的短距离位移；每段写明 `CONTINUITY IN / OUT`，下段继承上段姿态与空间关系。

## 十、Full-Reference Mode 六字段格式

每段提示词严格按以下固定顺序输出六个字段：



```
subject_definitions → summary → retention_analysis
→ detailed_description → overall_soundscape → non_diegetic_music
```
