# Case Study 015 — 下山2 · 面纱独舞十二段（XiaShan 2 · Veiled Solo Dance · Twelve Segments）

> 一支 141.845 秒的古风独舞(BPM 134.0,40 句唱词),切成 12 段分别生成再拼接。**双图分权参考**:PICTURE 1 = 正面全身照(**无头部信息**,只管正面服装)、PICTURE 2 = 三视图(只管脸部+背部,人物佩戴**只遮口鼻的半纱面纱**);分段 AUDIO 1 锁节拍网格(BPM 134.0 / beat 0.4478s / 首拍 0.441s)。编舞全部用**链记法**(入态→拍数→出态),段间用**特写续动转场**(每段 SHOT 01 = 上段结尾仍在运动的身体部位),Hero ×4 + 地面技术套件 + 运镜双模式(稳定/醉酒)。**本案例最大教训:一切规则拼进每一段,不存在全局段。**

## Inputs(输入)

- **PICTURE 1(正面全身照,无头部信息)**:唯一负责**正面服装与身体**—— outfit construction、layers、accessories 的正面视角;提示词零服装描写。
- **PICTURE 2(三视图)**:唯一负责**脸部**(五官/眉眼/发型)+ **背部**服装结构;并声明**半纱面纱只遮口鼻**(眼眉全露)与**安全裤设计**(仅一句)。
- **AUDIO 1(分段提供)**:BPM 134.0、beat 0.4478s、bar 1.7910s、首拍 0.441s;歌词原句按本地时间引作**对口型/节奏辅助锚点**(不做整段对口型)。
- **无视频参考**:参考动作全部经动链库文字转写(借姿势不借画面)。
- 十二段可直接粘贴的提示词全文:[`prompt.md`](./prompt.md)。

## The problem(实际踩过的坑)

1. **全局规则压底**:初版把 GLOBAL EXECUTION NOTE 放在文件最后——12 段都生成完才发现约束没生效。用户定规矩:**禁止全局段,不怕重复,一切规则拼接进每一段**;
2. **背景人物渗入**:场景词 "banquet / the host's side / a raised dais" 本身是人物磁铁;歌词锚「**有人**含笑频频举盏」的"有人"二字被模型直接画成宾客。修复 = 场景改写"人散后的空帐"+ 每段引文加负句 `the quoted lines never add people, guests or objects to the picture`;
3. **面纱被摘**:C4 链写成 "the veil slides aside"(主语就是面纱)——模型把穿戴面纱当道具摘下,且该"摘"无身体参与、不像舞蹈动作。修复 = **袖/纱词汇切分**(袖 = 舞蹈衣件、面纱 = 锁死穿戴物,袖过脸永不触碰面纱)+ C4 重写为完整身体动作(袖斜下扫 + 躯干螺旋上步 + 后点步);
4. **运镜只有推拉**:12 段相机全是 push/pull/pedestal。引入 **E7 弧形运镜**(arc tracking / snap zoom punch 卡重拍 / roll+荷兰角≤25° 瞬时 / 慢 orbit 仅旋转镜头)与 **E8 醉酒式镜头**;
5. **醉酒模式滥用风险**:第一视角失衡运镜若全片使用会失去质感——**只给 S03/S10/S11 三个情绪漂移段**(母规则全文内联进这三段),其余 9 段精确稳定相机,**稳定与失醇的对比**才让醉意被读出来;
6. **歌词政策反复**:初版全禁引用 → 澄清为三层结构:歌词原句+时间作锚点(可辅助对口型)/情绪弧线/面纱句,内容永不描述、永不演绎;
7. **低视角形容词被平均**:"camera tilted up 10-15°" 生成不出仰拍——特殊机位一律**物理化**(机位=场景里一件有位置的东西,见动链库 E5)。

## The breakthrough(写死的事)

### 1. 双图分权:每张图只管一件事

| 图 | 职责 | 明确不管 |
|---|---|---|
| PICTURE 1(正面全身,无头部) | 正面服装/身体 | 脸、背、环境 |
| PICTURE 2(三视图) | 脸(五官/眉眼/发型)、背部结构、半纱只遮口鼻、安全裤一句 | 环境、光线、姿势、构图、相机 |

配套 **VEIL_LOCK ×12**:面纱第一帧起全程佩戴,只遮口鼻,never removed / lifted / parted / made transparent,**No lyric ever causes it to disappear**;表达全部由眼、眉、头部角度承担。

### 2. 特写续动转场链(复用紫纱亭机制 + 切点原因)

每段 SHOT 01 = 上段结尾仍在运动的身体部位的特写,帧一即舞;段尾 TRANSITION 块写全**动作钩子 + Cut point(切点原因)+ 下段续动**。12 段特写接力:袖摆→上行袖→收腰手→展开手→翻转掌→折入肘→定形发→收拢手→下落袖→推帘手→腰间展手。

### 3. 链记法编舞:入态→拍数→出态

每段 = SUSTAINED LAYER(C1 提沉引擎每拍不断,holds 内也不停)+ 逐链【入态(承接上一链出态)→ 相对拍数分解 → 出态】+ 乐句尾镜头 pose + 至少一处**明写静止**("one full beat of absolute stillness")。密度按快板古风标准;旋转事件全片 2 次(S02 回身甩发 / S09 连环平转)。

### 4. Hero ×4 + 地面套件

H1 = S04 沉跪即起·High-Release Lock(30%);H2 = S07 掩口 Point&Lock mini(55%);H3 = S09 连环平转·Point&Lock(74%,全片高潮,裙摆开花+余烬光弧);H4 = S12 High-Release LINE Lock(96%)+ 终格俯首。地面套件 = S10:C9 坐姿后弯 → C32 侧卧高踢绷脚 120°(地面最高点)→ C28 侧卧→跪→立。

### 5. 运镜双模式(稳定 vs 醉酒)

稳定模式(默认,9 段):物理操作员、真实位置、膝-腰高度仰 5-15°、feature 降膝高 15-25°、never tilting down、orbit 仅旋转镜头且转速=环绕速度;词汇库:arc tracking / snap zoom punch 卡重拍 / roll+Dutch≤25° 瞬时 / 前景袖扫 / 重拍降机位。醉酒模式(S03 长耐心 / S10 长夜 / S11 去留张力):母规则全文内联进这三段相机块——observe → react late → overshoot → correct → reacquire;**只有相机醉,人物永不醉**;禁止 random shake / violent handheld / constant rolling。

### 6. 歌词三层结构

每段 LYRIC_RELATION = ①锚点层(歌词原句+本地时间,辅助对口型/节奏)+ ②情绪弧线(动作只表达情绪,不演绎内容)+ ③面纱句(口鼻在纱下随唱句轻微起伏,veil never comes off)。锚点引文自带负句:引文永不向画面添加任何人/物。

### 7. 拍网格纪律

BPM 134.0 / beat 0.4478s / 首拍 0.441s;全部块边界吸附 8 分位网格;歌词锚时间与 SRT 逐句核对(40/40 对位);段长与切割 manifest 12/12 精确一致。

## 提交工作流

1. 每段独立生成:附 **PICTURE 1**(正面全身照)+ **PICTURE 2**(三视图)+ **AUDIO 1**(该段 mp3);每段提示词自包含全部规则,单段粘贴即可;
2. 先跑 **S05** 验证两件事:背景是否仍被人渗入(宴帐空场测试)、面纱在 C21 逼近+露脸链中是否保持佩戴;
3. 12 段按切割清单时间轴(0.000 / 12.860 / 25.666 / … / 181.956)拼接,切点即特写匹配剪辑。

## Anchor check(提交前逐条过)

- **anchor coverage**:每段八锚齐备——双图锚、VEIL_LOCK(含袖/纱区分句)、SUSTAINED LAYER、背景零人物、歌词锚负句、Hero 标注、Cut point、调色模块;
- **continuity**:12 段特写接力逐一点名到部位(袖/手/掌/肘/发/裙摆),上段出态 = 下段入态,无"延续动量"式抽象交接;
- **timing**:全部时间戳自首拍 0.441 复算并吸附 8 分位网格,歌词锚 40/40 与 SRT 对位,段长与 manifest 12/12 一致;
- **physical causality**:动作链保持"脚→重心→胯→腰→肩→臂→腕→袖"因果顺序,袖只跟随不独立发力;
- **veil & background**:面纱句 in every frame;任何一段的场景描述都不含人物,引文不向画面添加任何人;
- **anti-copy distance**:参考动作全部经动链库文字转写,不附视频、不复用其人物/场景/镜头节奏。
