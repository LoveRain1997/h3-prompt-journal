## 核心方法

### 1. 分段独立生成 + 局部特写开场匹配（拼接流畅性的根基）

每段都是**完整独立的舞蹈表演**：不继承前一段身体姿态，不要求 H3 自动续接上一段动作。段间接缝靠**剪辑匹配**完成——S1 段尾伸向镜头的开放手掌 ↔ S2 前景开放手掌开场；S2 段尾举起的前臂斜向构图 ↔ S3 前臂手腕肩部特写；S3 段尾投篮 follow-through 的手掌 ↔ S4 前景指尖特写。只匹配手掌大小、前景位置、手指方向与镜头运动方向。三行匹配表见 [`prompt.md`](./prompt.md) 文末。

### 2. 虚空篮球的三个可信条件（全程无实体球）

- **接球**：双手形成球体周围的弧形空间，掌间有可信间距；
- **运球**：一只手向下带动、另一只手辅助换手，重心随动；
- **投篮**：非投篮手先离开 → 投篮手完成伸肘、腕部释放和指尖跟随——五阶段 Gather/Load/Drive/Release/Follow-through 分别展开，能量从脚底经腿、骨盆、躯干、肩、肘传到指尖。
- 球始终不可见：禁止透明球、光球、粒子球或轨迹特效；歌词「篮球转呀转过来」只在篮球歌词启用虚空动作，其余歌词靠节奏、律动、表情表达（**歌词不做逐字哑剧**）。

### 3. 全片折腕禁令（Broken Wrist ban）

不做刻意向内/向下/侧面折出角度的手腕造型，不把折腕当定格手势；普通手势中手腕自然延续前臂方向；投篮只保留真实、短暂、连贯的出手跟随。该禁令在每段「PERFORMANCE CHARACTER」重复出现——单一提示词段内规则要在段内自带。

### 4. 物理运镜：醉酒式流动摄影

镜头路径写物理事实（离地 25–35cm 贴鞋高度、沿小臂后退、绕外侧肩、高度与焦点变化），**不用角度数值标签**；允许短暂经过手臂/头发形成前景遮挡再揭示面部，但不长时间挡脸、不鱼眼不拉伸；人物面部保持清晰。

### 5. ComfyUI 本地生成工作流（[`comfyui-workflow.json`](./comfyui-workflow.json)）

四段在本地 ComfyUI 用 H3 节点生成：`MiniMaxH3ReferenceToVideo` ×2（主生成）+ `MiniMaxH3AddGuide` 续接组（**上段末帧喂给下段作 guide**，配合 `GetImageRangeFromBatch` 取帧、`TrimAudioDuration` 精确切音频）+ 加速 lora 组 + 参数区。工作流来自 B 站 UP 主**敢抢我神棍名号**。官网/本地两用：官网直接喂图+切片；本地用续接组让段间帧级过渡更紧。

## 可复用经验

1. **「分段独立 + 特写匹配」优于「让模型续接动作」**：模型跨段记忆是动作崩坏与身份漂移的根源；每段给完整结束姿态、下段只匹配局部构图，拼接处反而最干净。
2. **高 BPM（150.5）的容量纪律**：有速度与活力，但不逐拍换动作——用 2 拍/4 拍连接单元 + 完整动作链（准备重心→发起→扩展→强拍→回收→衔接），跳跃必写屈膝缓冲。
3. **mime 类主题的写法**：不存在的道具要写「双手关系+空间轨迹+视线」三个可信条件，同时三重禁止（实体球/特效球/轨迹）压住模型补全冲动。
4. **规则自带进每段**：折腕禁令、无新增元素、不逐字拍歌词等全局规则在每段提示词内重复出现，段间不依赖任何外部记忆。
