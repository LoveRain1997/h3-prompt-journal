# Case Study 018 — 抬腿丝袜卡点换装（Leg-Lift Ground-Contact Stocking Cut · Six Looks）

> 一支 5.17 秒的服装展示镜头：**永久支撑腿纹丝不动**，**活动前腿节奏点地**，每次"脚底接触石面"的物理瞬间触发一次**袜饰硬切**——六次点地 = 六款 LOOK（LOOK 0→6）。换装的触发器不是时间戳、不是渐变，而是一个**可读的物理事件**（CONTACT = CUT）。源片为 AnimateDiff 补帧的平滑 morph，本案例把它**升级为干脆的接触式剪辑**，并给出逐次时间轴。

## Inputs（输入）

- **PICTURE 1（万能锚）**：角色（金发幻想少女、珠光蓝白礼裙、花饰、白色高跟鞋）**与场景**（夜晚哥特城堡广场、发光喷泉、复古路灯、湿石地面）双锁——正文零外貌/场景外描写。
- **VIDEO 1**：**只借机制**——节奏点地动作、beat 间距、硬切时序；其人物/服装/走廊环境全部丢弃。
- **AUDIO 1**：原片音轨 1:1 复用（点地声即节拍）。
- 完整提示词全文：[`prompt.md`](./prompt.md)。

## The problem（踩过的坑）

1. **换装触发器写成了时间戳**：只给换装时刻，模型会提前/延后——触发器必须是一个**物理事件**；
2. **接触与下一次抬腿被压缩成一个动作**：cut 和 lift 黏在一起，新袜还没显形脚就抬走了；
3. **支撑腿漂移**：换装几次后重心腿悄悄挪位，构图崩；
4. **平滑 morph 源片误导**：AnimateDiff 补帧源是渐变换装，直接照抄会得到"袜子渐变融化"——必须**升级**为干脆的接触式硬切。

## The breakthrough（写死的事）

### 1. CONTACT = CUT（物理事件触发剪辑）

袜饰只在"活动脚的白色鞋底**第一次清晰接触湿石面**的那一帧"硬切。剪辑被锚定在物理上，观众读到的是"脚落地 → 世界换了"。

### 2. 时序解耦四段律

**CONTACT → CUT → PLANTED HOLD → STOCKING STABLE → NEXT LIFT**
切≠下一次抬腿：切后前脚**原地保持**一个可见 hold，新袜在脚仍在地面时完全显形稳定，之后才允许下一次抬腿。

### 3. 永久支撑腿 + 单一活动腿

后/远腿 = 永久支撑腿：膝紧、踝稳、跟趾钉地，全程不变（**连续性锚**）；前/近腿 = 唯一节奏腿：抬 → 降 → 触地 → 保持 → 释放的紧凑循环，永不承担支撑。髋始终居中于支撑腿正上方。

### 4. 六款 LOOK 状态机

LOOK 0（图1 白色花纹过膝+金钻扣）→ 1 黑丝蕾丝硅胶袜口 → 2 黑色绑带束网+不对称吊袜夹 → 3 透视黑丝+豹纹宽袜口 → 4 灰白花卉提花过膝 → 5 斜纹透视黑丝 → 6 素黑丝。每次点地一换，机制完全相同。

### 5. 声画同帧

脚降 → 鞋底触石 → **触地声** → 画面硬切新袜——声音事件与视觉剪辑在同一接触时刻。

### 6. 源片 morph 的 H3 升级

AnimateDiff 补帧源是平滑渐变换装；H3 版把它转写为 **ground-contact costume edit**——每个换装点从"渐变"升级为"接触即切"，物理因果可读。

## 提交工作流

1. 整段一次生成：附 **PICTURE 1**（万能锚）+ **AUDIO 1**（原声 1:1）+ **VIDEO 1**（机制参考，可选）；
2. 六个接触时刻(2.070 / 2.400 / 2.730 / 3.170 / 3.570 / 4.030)逐一核对：触地声与新袜硬切同帧；
3. 5.17s 单镜头直出，无拼接。

## Anchor check（提交前逐条过）

- **anchor coverage**：万能锚（角色+场景双锁）、支撑腿永久规则、活动腿循环、六 LOOK 状态机、接触=剪辑、声画同帧；
- **continuity**：切点前后脚位/支撑腿/躯干/髋零位移——只有袜饰变；
- **timing**：六个接触时刻即换装时刻；每次接触后有可见的 planted hold；抬腿始于接触时刻之前；
- **physical causality**：抬→降→触地→保持→释放的完整物理循环，力的来源（支撑腿）永不中断；
- **anti-copy distance**：VIDEO 1 只借机制（节奏点地+切换时序），人物/服装/场景全部来自 PICTURE 1。
