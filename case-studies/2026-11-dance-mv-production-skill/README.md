## 实测依据

本 Skill 不是凭空总结的规范，而是从已跑通的项目中归纳：

- 《Index's Morning Trouble》H3 Commercial MV Prompt Pack Rev.8.7（178 BPM、18 个独立片段、现代商业 J-pop／夏日 Idol MV）
- 《画楼春梦》仙侠紫韵花楼剧情 MV
- 《灵犀照月》古风水舞
- 《Index Morning Trouble》宋玉古典舞镜头方案

## 它要解决什么问题

H3 舞蹈 MV 的常见失败不是参数问题，而是流程倒置：先堆动作名称再塞进音乐、先堆镜头术语再让模型自己猜舞、先写形容词再期待 H3 脑补身体如何运动。结果是人物站立摆姿、镜头随机推拉、片段之间互相不连续。

本 Skill 的目标是把音乐、身体编舞、摄影机、剪辑、参考图和 H3 多模态提示词组织成一套**可以反复执行、检查、修订和复用的商业 MV 工作流**。

## 四层交付目标

每支 H3 舞蹈 MV 的最终交付必须同时满足：

1. **音乐层：** 动作真实响应当前 Audio 1 的速度、拍点、重拍、乐句、段落能量与留白。
2. **舞蹈层：** 完成可辨认、有身体动力学、动作因果、节奏层次和风格特征的完整舞句。
3. **摄影层：** 摄影机是表演的一部分，有真实空间位置、运动路径、构图目标、同步时机和剪辑动机。
4. **生成层：** H3 能在每个独立片段中读懂主体、参考图职责、音频、动作、镜头、场景与连续性；提示词完整、自包含、可执行、可检查。

## 制作总公式

```
音乐结构 → MV 概念 → 视觉母题 → 舞种语法 → 动作链 → 身体动力学
→ 摄影机轨迹 → Shot 切分 → 段间视觉钩子 → H3 完整提示词 → 生成检查 → 定向修订
```

## 十条最高优先级原则

1. 音乐优先于文字，Audio 1 是动作与时长的真实依据。
2. 舞蹈优先于歌词字面，歌词不逐句变成道具、动作或表情。
3. 动作必须完整：起始状态、动力来源、过程、完成点、惯性回收、下一动作入口。
4. 相机与身体共用时间轴，动作的启动、扩张、峰值、恢复驱动摄影机同步响应。
5. 机位必须物理化，不依赖抽象角度标签。
6. 舞种必须区分，古典舞身韵不能直接替换成街舞或 K-pop 手势。
7. 参考图职责必须明确，人物、场景、构图、路径、道具各有权威来源。
8. 每段必须独立成立，在该段提示词内重写必要的锁与规则。
9. 段间连续靠剪辑设计，不靠模型猜测继承。
10. 复杂度服从时长，一个清楚的舞句远胜于短窗口里塞五个高级动作。

## 动作描述三档密度

| 档位 | 动作类型 | 描述方式 |
|---|---|---|
| A 档：自然动作 | 日常、轻微反应 | 一句写清目标、过程、结果与情绪，不拆关节 |
| B 档：标准舞蹈链 | 舞步、律动、上肢组合、身体波浪 | 写清支撑脚、重心、路径、拍点、重拍、回收与下一入口 |
| C 档：Hero 技巧 | 高难度跳跃、旋转、地板、翻腾 | 写完整技术阶段、动力源、轴线、空中形态、落地与制动 |
