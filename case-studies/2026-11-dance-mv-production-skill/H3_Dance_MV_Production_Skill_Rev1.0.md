# MiniMax H3 舞蹈 MV 制作 Skill

**Production Methodology · Dance Choreography · Cinematic Camera Grammar · Segment Prompt Engineering**  
**版本：Rev.1.0｜2026-11-05**  
**适用范围：现代流行 MV、J-pop、K-pop、甜系 Idol、Jazz Funk、Hip-hop、街舞、啦啦队、现代舞、古风舞、汉唐舞、宋韵舞、仙侠袖舞、敦煌风、国风融合舞、单人／双人／群舞。**

> 本文件是 MiniMax H3 舞蹈 MV 的完整制作方法论与提示词生产规范。它不是某一支 MV 的成片脚本，也不是动作名称词典。目标是把音乐、身体编舞、摄影机、剪辑、参考图和 H3 多模态提示词组织成一套可以反复执行、检查、修订和复用的商业 MV 工作流。
>
> **主要实测依据：**《Index's Morning Trouble》H3 Commercial MV Prompt Pack Rev.8.7（178 BPM、18 个独立片段、现代商业 J-pop／夏日 Idol MV）；《画楼春梦》仙侠紫韵花楼剧情 MV；《灵犀照月》古风水舞；《Index Morning Trouble》宋玉古典舞镜头方案；《舞蹈动链 H3 库 Rev.1.4》及其物理机位、动作链、运镜与生成验收规范。

# 0. Skill 的核心定位与最高优先级

## 0.1 核心目标

制作 H3 舞蹈 MV 时，最终交付必须同时满足四个层面：

1. **音乐层：**动作真实响应当前 Audio 1 的速度、拍点、重拍、乐句、段落能量与音乐留白。
2. **舞蹈层：**人物完成可辨认、具有身体动力学、动作因果、节奏层次和风格特征的完整舞句，而不是站立摆姿、原地摇晃或走路填时间。
3. **摄影层：**摄影机是舞蹈表演的一部分。相机具有真实空间位置、运动路径、构图目标、同步时机和剪辑动机，而不是随机推拉、空绕或远距离旁观。
4. **生成层：**H3 能在每个独立片段中读懂主体、参考图职责、音频、动作、镜头、场景、连续性和结束状态；提示词完整、自包含、可执行、可检查。

## 0.2 制作总公式

**音乐结构 → MV 概念 → 视觉母题 → 舞种语法 → 动作链 → 身体动力学 → 摄影机轨迹 → Shot 切分 → 段间视觉钩子 → H3 完整提示词 → 生成检查 → 定向修订。**

不可倒置为：先随意堆动作名称，再把动作塞进音乐；先堆镜头术语，再要求模型自行完成舞蹈；先写漂亮形容词，再期待 H3 猜出身体如何运动。

## 0.3 十条最高优先级原则

1. **音乐优先于文字。** Audio 1 是动作与时长的真实依据；歌词不能推翻音频节奏。
2. **舞蹈优先于歌词字面。** 除非明确制作剧情 MV 或 Spoken 表演，歌词不逐句变成道具、动作或表情。
3. **动作必须完整。** 每个时间窗至少要有起始状态、动力来源、动作过程、明确完成点、惯性与回收、下一动作入口。
4. **相机与身体共用时间轴。** 同一动作的启动、扩张、峰值、恢复必须驱动摄影机同步响应。
5. **机位必须物理化。** 用相机在哪里、离地多高、离人物多远、从哪边看、沿什么路径移动来写；不依赖抽象角度标签。
6. **舞种必须区分。** 古典舞的提沉、拧倾、云手和袖势，不能直接替换成现代街舞的胸击、胯部 Groove 或 K-pop 手势组合。
7. **参考图职责必须明确。** 人物、场景、构图、路径和道具各有权威来源，不能互相覆盖。
8. **每段必须独立成立。** H3 每段独立生成，必须在该段提示词内重写必要的角色锁、场景锁、声音规则和本段镜头动作。
9. **段间连续靠剪辑设计，不靠模型猜测。** 前段末尾与后段开头可以建立动作／方向／形状匹配，但不能默认 H3 自动继承上一段视频状态。
10. **复杂度服从时长。** 在给定时间内完成一个清楚的舞句，远胜于把五个高级动作压缩在同一个短窗口里。

## 0.4 “节奏平衡型动作设计”三档描述密度

每个动作先判断属于哪一档，再决定提示词细节量：

| 档位 | 动作类型 | H3 描述方式 | 常见实例 |
|---|---|---|---|
| A 档：自然动作 | 常识性日常、轻微反应、生活动作 | 一句描述动作目标、自然过程、可见结果与情绪即可，不拆解每个关节 | 伸懒腰、翻页、拿杯、坐下、回头、惊讶、整理袖口 |
| B 档：标准舞蹈链 | 大多数舞步、律动、上肢组合、身体波浪 | 写清支撑脚、重心、动作路径、拍点、主重拍、回收和下一动作入口 | Step-touch、交叉步、侧压、猫爪、绕腕、身体波浪、展臂 |
| C 档：Hero 技巧 | 高难度跳跃、连续旋转、地板动作、倒立／翻腾、强技术线条 | 写完整技术阶段、动力源、轴线、空中形态、落地和制动；必要时拆分多个时间窗 | Grand Jeté、紫金冠跳、连续平转、探海翻身、地板滚动起身 |

**节奏平衡要点：**快歌必须有速度感和能量，不能用慢动作违背 BPM；但也不能每一拍都发明一个独立动作。动作的“密度”来自节奏化的持续 Groove、动作路径、重音、反拍和方向变化，不是动作名数量。普通生活动作不要被写成复杂舞蹈机制；只有真正的舞蹈技术才需要动力学拆解。

# 1. 完整制作工作流

## 1.1 第一步：素材与约束登记

动笔前先建立素材清单，不能凭文件名猜内容：

- 当前完整音频、每个候选切片、字幕／歌词文件、节拍分析 JSON、cuts manifest。
- 所有 Picture 参考图，并逐张确认它们实际提供的是人物、环境、机位、构图、动作姿势、路径还是道具。
- 动作库的最新版本及本项目可用动作链。
- 用户特别指定的摄影机预设、风格、服装锁、环境限制、禁止新增项、舞蹈强度与画幅。
- 是否允许剧情、是否允许其他角色、是否允许 Spoken、是否要求纯舞蹈／不唱口型／不出现第二人物。

先登记“必须保留”和“禁止发生”两栏。不能只罗列用户想要的内容，而忽略其明确禁止模型擅自添加的元素。

## 1.2 第二步：音乐结构分析

至少确认：

| 项目 | 必须确认的内容 | 用途 |
|---|---|---|
| 总时长 | 精确到毫秒或可用的最细精度 | 片段总长度、结尾检查 |
| BPM | 主速度；若存在半拍／双倍拍感，另记身体 Groove 感受 | 估算拍长与动作速度 |
| Beat | 单拍时长 | 动作启动、短动作完成点 |
| Bar | 小节时长 | 舞句组织、八拍组合 |
| Phrase | 常见乐句长度 | 镜头段落、动作完整句、转场点 |
| First downbeat | 音频首个真实重拍偏移 | 避免片段 0 秒即错误踩拍 |
| 音乐段落 | Intro／Verse／Pre-Chorus／Chorus／Bridge／Final Chorus／Outro 等 | 舞蹈强度与镜头语言变化 |
| 变化事件 | 鼓组进入、Bass、Fill、Break、停顿、Drop、尾音、旋律变化 | 动作峰值与剪辑触发 |
| 人声事件 | 歌唱、Speaking、呼吸、静默、长音 | 是否需要口型和面部稳定镜头 |

### 节奏计算

- `beat_duration = 60 / BPM`
- `bar_duration = beat_duration × 每小节拍数`
- `phrase_duration = bar_duration × 乐句小节数`
- `beat_position = (local_time - first_downbeat_offset) / beat_duration`

以上只用于计算和检查；**不要把未经音频验证的拍点写成确定的音乐事件。** 若有可靠 cuts manifest，优先采用其已验证时间码。若没有，应先分析音频，再确定动作窗口。

### 节奏与身体的正确关系

- 快歌：身体有持续速度和弹性，动作可以跨数拍展开；用脚步、重心、手臂和躯干的层次制造丰富性。
- 中速：强调 Groove、重量变化、停顿、身体波浪、方向推进和重音的弹性。
- 慢歌：动作数量减少，但动作本身要有连续的动势、延迟、呼吸、张力与释放，不能把慢歌理解为没有编舞。
- 强拍不等于每个强拍都要做一个大动作。可在强拍上做落点，也可用提前预备、反拍释放或延迟回收形成韵律。
- 音乐留白不等于人物停止。可以用呼吸、眼神、手腕余韵、重心继续转移、裙摆／发丝滞后运动保持生命感；若需要真正静止，必须明确写出静止的拍位与时长。

## 1.3 第三步：先确定 MV 的创意方向

确定这支 MV 的主类型，避免写成互相冲突的混合物：

- **纯舞蹈 MV：**以动作、编舞、视觉表演和摄影机为主，不需要剧情事件。
- **舞蹈主导的剧情 MV：**允许少量叙事钩子，但人物大部分可用时间仍在音乐中表演。
- **情绪肖像 MV：**用舞蹈、姿态、眼神、空间和服装动态表达情绪，动作密度服从歌曲。
- **群舞／队形 MV：**重点是队形图形、主次关系、接龙、同步、层次和调度。
- **古风意境／叙事舞 MV：**用身韵、衣袖、空间层次与情绪推进表达主题；不是风景片，也不是道具逐字演歌词。

### MV 创意圣经必须回答

1. 一句话概念是什么？
2. 主体是谁？是否只有一位舞者？
3. 视觉世界是什么？哪些空间和颜色是主识别？
4. 主要舞种是什么？融合舞种如何服务主舞种？
5. 全片的视觉母题是什么（圆形、线条、镜面、纱、门框、花影、窗光、几何地面等）？
6. 哪些歌曲段落提高动作能量，哪些段落收束？
7. 主要摄影语言是什么？哪些镜头必须留给完整舞步？
8. 有哪些不能改变的视觉元素、不能出现的对象和不能新增的道具？

### 不把歌词拍成插图

歌词只作为情绪、态度、关系和主题的资料。先提炼抽象动词与情绪，例如“得意、逃逸、挑衅、回望、失重、释放、亲密、反转”，再转成舞蹈和镜头。歌词写到“酒”不代表要生成酒壶；写到“等待”不代表人物要站着等；写到“海”也不必切海景。若项目明确是叙事 MV，可选择少数关键意象作为视觉母题，但不要每句歌词都对应一个物件或哑剧动作。

## 1.4 第四步：建立全片舞蹈能量曲线

先画整首歌的能量曲线，再决定动作和镜头：

| 音乐位置 | 常见舞蹈策略 | 镜头策略 |
|---|---|---|
| Intro | 建立个人节奏、独特动作语言、第一记识别性动作 | 视觉钩子、近身揭示、短促开场机位变化 |
| Verse | Groove 稳定，细节多于幅度，建立人物个性 | 中近景与全身交替，允许局部细节 |
| Pre-Chorus | 动作逐渐扩张，重心／手臂／方向逐级累积 | 画面空间逐渐打开，镜头提前为高潮跑位 |
| Chorus | 最高识别度动作、完整舞句、位移与方向变化 | 更宽景别、强拍构图、动作匹配剪辑 |
| Bridge | 释放对比：抽离、停顿、低重心、不同舞种或不同机位 | 摄影语法明显改变，但不无故换场 |
| Final Chorus | 变奏而非机械重复；动作幅度与镜头层次再次提升 | 更丰富的机位组合、高潮快切或长舞段 |
| Outro | 动作逐层收束，利用惯性和余韵结束 | 镜头缓停、拉开或在最终动作完成时结束，不提前冻住 |

**全片不可只有一种景别、一个动作族、一种手势或一种运镜。** 副歌可以保持一个较长镜头，但应通过队形、动作幅度、人物与镜头的空间关系制造变化。

# 2. 参考图与视觉锁定系统

## 2.1 总原则：先判读素材，再声明职责

每个项目都必须在 MD 中写一份“图片职责表”，并在每个独立 H3 段落中重复必要的职责。图像的角色不能默认通用；不同项目的 Picture 数量和功能可以不同，但任何一张图都不能同时被模糊地当作人物、场景和镜头的全权来源。

## 2.2 最近四图 MV 工作流（现代 MV 默认示例）

这是近期《Index》18 段 MV 的四图结构，适合作为需要人物、镜头路径和环境同时控制的现代 MV 默认模板：

| 输入 | 唯一职责 | H3 使用规则 |
|---|---|---|
| `<Picture 1>` | 主角身份与外观锚点 | 唯一人物身份权威；锁定面部辨识、发型、体型比例、服装结构、颜色、配饰和既有渲染质感。不得让其他图片覆盖人物身份。若用户要求只锁图1，不要额外重述、改写或扩展人物外貌。 |
| `<Picture 2>` | Storyboard／构图／摄影机语言参考 | 只读取景别、主体位置、画面几何、摄影机与人物的相对关系、前后景关系和镜头运动方式；不复制其人物、服装或环境。 |
| `<Picture 3>` | 空间调度／人物路径／摄影机路线参考 | 只提取人物走位、进出画方向、空间连接、机位路径、遮挡关系；必须将路线落实在 Picture 4 实际支持的场景空间中。 |
| `<Picture 4>` | 场景环境母版 | 唯一实际场地权威；锁定建筑结构、墙地面、门窗、家具位置、材质、色彩、陈设密度和光线逻辑。不能凭空增加房间、窗户、家具、装饰或户外场景。 |
| `<Audio 1>` | 当前片段唯一音频与局部时间权威 | 保留原声，当前片段从 00:00.000 起算，动作与镜头根据此切片安排。 |

冲突优先级：**人物外观由 Picture 1 决定；环境由 Picture 4 决定；Picture 2／3 只指导镜头和路径；动作／镜头时间由 Audio 1 与已核验的 cuts manifest 决定。**

## 2.3 三图古风舞蹈模板

在《画楼春梦》一类古风项目中，可使用：

| 输入 | 唯一职责 |
|---|---|
| `<Picture 1>` | 女主身份与外观锚点。 |
| `<Picture 2>` | 指定镜头的真俯拍／Overhead 构图参考。只在需要严格俯拍的 Shot 中调用。 |
| `<Picture 3>` | 古风建筑、空间、家具、色彩、材质与光线参考。图中若有其他人物，忽略其人物身份。 |
| `<Audio 1>` | 当前切片的音乐时间轴。 |

古风项目不应把 Picture 2 的俯拍透视误用到全片。若只在一段使用正上方俯拍，必须在那一段单独声明；其他段落正常使用贴身、平行、低位、肩后、侧前方等物理视点。

## 2.4 单图锁定与全能参考

当用户只提供一张人物／环境合一的图片，并要求“图1锁定”时：

- 先明确 Picture 1 是身份锁定、环境锁定，还是人物＋环境的全能参考。
- 若是全能参考，尽量保留原始构图世界、人物与场景关系、色彩、光线和视觉质感；只允许执行指定动作与镜头变化。
- 若是人物身份锁定，则不要默认把 Picture 1 的背景也冻结；必须由用户或其他参考确定环境。
- 若用户只要求“锁图1人物”，提示词避免冗长重绘人物外貌、服装与身体细节；写“preserve the exact existing identity and outfit from Picture 1”比重新描述一遍更稳定。

## 2.5 参考图冲突处理与视觉资产账本

建立以下表格：

| 资产 | 唯一来源 | 可改变 | 不可改变 |
|---|---|---|---|
| 人物脸／身份 | 指定人物图 | 表情、视线、姿态 | 面部几何、身份辨识 |
| 发型／配饰 | 指定人物图 | 随动作产生的自然惯性 | 样式、颜色、长度、配饰数量 |
| 服装 | 指定人物图 | 布料自然摆动、受风惯性 | 款式、结构、颜色、层次、附加服饰 |
| 场景 | 环境母图 | 镜头观察位置、景别、可见区域 | 建筑结构、固定家具、墙面、地面、门窗关系 |
| 道具 | 明确出现的参考／用户指定 | 真实使用动作 | 不得无故复制、替换、变形或增加 |
| 摄影机路径 | 分镜／路径参考＋导演设计 | 在原场景可执行范围内调整 | 不可借路径参考偷换环境 |
| 视觉特效 | 用户明确允许的效果 | 强弱与镜头呈现 | 不得凭空变成法术 UI、游戏特效或不属于项目的道具 |

**道具账本：**每个道具记录名称、来源、数量、所在位置、首次出现、最后出现、是否允许被拿起、是否允许在镜头间保持连续。禁止 H3 自行增加“看起来合理”的椅子、镜子、植物、花瓶、桌子、灯、书、伞或其他物件。

## 2.6 视觉一致性锁定文本原则

- 锁定句只写必要的固定事实，不要在每个段落重写一大段人物外观。
- 环境锁优先描述实际可见结构，不写抽象的“漂亮房间”“华丽宫殿”让模型自由发挥。
- 参考图中没有的东西不因歌词、情绪或舞蹈风格自动出现。
- 不要用一长串否定词替代明确的正向空间定义；只在高风险冲突处添加短而具体的禁止项。
- 若某个元素需要保持不变，写清楚它的来源和保持范围，而不是只写“consistent”。

# 3. 舞种分类与动作语法

本章用于先确定“身体如何跳”，再决定具体动作。可融合，但必须有主舞种；融合部分需要有动机，不能把不同舞种动作无规则拼盘。

## 3.1 中国古典舞／国风身韵

**核心气质：**气息带动身体，线条有方向，重心有虚实，动作有含蓄的动力与延迟。不是慢动作古装摆姿，也不是手腕一直旋转。

### 持续层

- 提沉呼吸：呼气时含胸、沉肩、重心下行；吸气时脊柱逐节提起、胸腔舒展。
- 重心的虚实转换：实脚承重，虚脚点、擦、探、盖、移；脚下必须有可信支点。
- 身体的拧、倾、冲、靠：先由骨盆和胸肋建立方向，再带动肩臂与头眼。
- 头眼节奏：眼神先行、头部随后、躯干再跟随；不可全身同时硬转。
- 袖、裙、发的滞后：身体先动，布料随后跟进，动作停下后仍保留短暂惯性。

### 常用动作族

| 动作族 | 动作逻辑 | 编排用途 |
|---|---|---|
| 云手／双臂云手 | 双臂走连续弧线，肘腕依次领动，掌面方向不断变化 | 舞句连接、画圆、展示身韵 |
| 穿掌／翻掌 | 一只手沿另一只手臂或身体中线穿出，掌心在路径中翻转 | 细腻节奏、方向转换 |
| 提沉／含腆 | 胸腔、脊柱与头部有呼吸性的收放 | 慢板、情绪段、动作起势 |
| 冲靠／拧倾 | 骨盆与胸腔产生反向扭转或侧向倾斜 | 方向感、力度、身韵层次 |
| 盖步／点步／弧线步 | 脚步沿弧线改变支撑关系，而非重复交叉原地踩 | 位移、转向、空间调度 |
| 涮腰／旁提 | 从腰胯开始带动躯干弧线，逐节完成 | 柔韧线条、情绪释放 |
| 撩袖／甩袖 | 肩肘腕带出袖片，袖端滞后、扩张、回落 | 古风视觉记忆点、镜头遮挡转场 |
| 轴转／点步翻身 | 先建立轴心和支撑，再转体、定向、制动 | 乐句高点、Hero 动作 |
| 探海／控制延伸线 | 支撑脚稳定，腿部和躯干形成反向平衡线 | 画面雕塑感、技术线条 |

### 快板古典舞

- 使用更短的穿掌、翻腕、盖步、点步、快转、袖线切分与反拍眼神。
- 身韵仍在，但要有清楚重拍；不能把快板写成整段缓慢飘袖。
- 每个短时间窗只安排一个主要动作结果；快速的多个小变化可以归属于同一条连续动作链。
- 镜头可以在袖端、掌心和脚步之间转换，但不能连续遮掉关键支撑脚。

### 慢板古典舞

- 动作数量减少，强调提沉呼吸、重心滑移、身段延迟、眼神先行、袖摆余韵。
- 不要用无意义的慢速走路代替身韵。
- 长线条需要明确支撑点和反向平衡；静止时写明停留时长与呼吸状态。
- 摄影机可做近距离弧线、缓慢平行横移、从衣料细节回到人物面部，但不能持续绕静止人物空转。

## 3.2 汉唐舞／宫廷舞／古典礼仪型舞蹈

- 以端庄的轴心、挺拔躯干、清晰手位、稳定步法与对称构图为主。
- 汉唐风可使用有力量的袖臂展开、圆场步、翻身、踏步、立身线条；强调节奏与身体重心，不要只把它写成“仙气飘飘”。
- 宫廷舞的手势、姿态和转身需要克制、有礼仪感；群舞时重视队形、对称、层级与主次。
- 对称不是全身机械镜像；可以在同一构图中做有控制的错位、前后层次和领舞响应。
- 服装较宽大时要让动作路径留出布料反应空间，防止袖子、裙摆穿模或遮挡脸部。

## 3.3 宋韵／江南／婉约国风

- 以小幅度、细节化、留白、柔和重心流动、袖口和手腕线条为主。
- 常用脚尖点地、轻盖步、侧身转向、回眸、手腕翻转、扇形手臂路径（仅当扇子已被允许）和坐／立高度变化。
- 眼神往往先于头部，头先于肩，肩再带动躯干；不可变成单纯歪头摆拍。
- 空间不必一直大幅移动，可使用地面／跪／立的高度变化、屏风／窗格／帘幕的前后层次制造镜头变化。
- 扇子、团扇、酒盏、琴等只在参考图或用户明确允许时出现；歌词中提到不代表可新增。

## 3.4 仙侠／袖舞／敦煌融合

- 仙气来自身韵、空间、材质、光线、雾／水／风与动作线条的共同作用，不依赖粒子泛滥和发光 UI。
- 袖舞重点写袖片如何被手臂带起、如何延迟展开、如何改变方向、如何回落；袖子是身体动作的延伸，不是独立漂浮的装饰。
- 敦煌风可采用更开阔的手臂弧线、翻掌、斜向延伸、躯干侧倾和多层次身段；注意线条来源与身体支点。
- 水舞／镜湖舞需明确脚底与水面的接触、涟漪的出现位置和传播方向；除明确指定外，不要让人物持续悬浮。
- 环境变化必须遵守视觉圣经；同一片湖岸不能无理由跳成宫殿、庭院、船舱或陌生山谷。
- 风暴、雷光、雾和水墙应有物理位置、真实方向、连续变化和适度强度；不要生成游戏护盾、魔法圆环或无关符文。

## 3.5 J-pop／甜系 Idol／宅舞

**核心气质：**明快、轻弹、可读、亲和、动作识别度高，手势多但不要只剩手势。

### 持续层

- 自然的膝部弹性、脚掌前后重心、轻微内扣或轻弹；根据参考舞种确定默认 Groove。
- 头部和眼神作为反拍小节奏，不必让手臂每拍都做动作。
- 手势通常收在肩宽附近，脸部附近动作需避免遮嘴；大扩展动作才允许超出肩宽。

### 常见动作族

- 内八膝弹跳、侧点脚尖、脚跟回弹、并脚小跳、后踢小跳。
- 猫爪、脸颊框脸、敬礼歪头、胸前拼心、头顶比心、双臂 X-open、斜上 V、胸前交叉再展开。
- 交替小拳、短促指向、肩部轻击、手腕颤动、双手捧脸、背手点脚。
- 交叉步、侧向 step-touch、快速重心交换、轻微 pivot、横向 skater-hop。

### 设计纪律

- 甜系动作必须同时有脚下节奏和身体弹性，不能全身只有手势。
- 猫爪、拼心、敬礼、V 手势等招牌动作可重复为全曲视觉主题，但要改变进入方式、方向、景别或后续动作，避免每段同样摆一次。
- 可爱手势保持较小半径；若手部动作复杂，减少其他关节同时变化，避免 H3 生成畸形手指。
- 手指数目不需要反复复杂定义。用户只指定简单 V 字时，就写简单 victory V-sign，不附加多余计数手势、指头拆分或变化过程。

## 3.6 K-pop／现代商业舞蹈

**核心气质：**清晰重拍、队形图形、动作线条、节奏层次、主副歌记忆点和舞台表现。

### 常见动作族

- Groove bounce、step-touch、cross-step、heel-toe、skater step、side press。
- Hip figure-eight、pelvic accent、rib isolation、chest hit、shoulder hit。
- Arm pathway、diagonal drive、wide open line、cross-and-release、wrist roll、body wave。
- Half-turn、quarter pivot、direction switch、跳跃组合、落地缓冲。
- Point choreography 可成为副歌记忆点，但不要让全曲重复同一个指向动作。

### 编排纪律

- 用脚步和重心决定身体的方向变化，手臂动作不能独立漂浮。
- 副歌动作要有明显记忆点：一个主形状、一条主路径、一次完整重拍或一个有辨识度的组合。
- 大动作与小动作交替：宽幅开臂之后可接小幅手腕／肩部细节，避免整段持续最大幅度。
- 群舞需定义队形、层级、进退顺序和主角轮换；单人舞不必模仿群舞队形。
- 不要把所有成员写成僵硬完全同步；允许主舞先启动、其他舞者错位跟进，制造呼吸感。

## 3.7 Hip-hop／Street／Popping／Locking／Tutting

- **Hip-hop Groove：**重心下沉、膝部弹性、躯干松弛、步伐与上身反向关系；不要写成直立机械挥臂。
- **Popping：**通过清楚的肌肉收缩形成 hit，身体隔离、wave 和 Dime Stop 之间要有动力转换，不要连续乱抖。
- **Locking：**动作蓄力、快速锁定、夸张线条、表情和释放；Lock 需要确切落点，不是长期僵硬。
- **Tutting：**关节形成几何框架，手臂角度关系清晰，路径简单可靠；避免同一时间要求过多手指精细动作。
- **Breaking：**必须描述进入、支撑、地面路径、旋转／动力来源、出地和恢复；危险或高难技巧应有完整时间窗，不能只写“做一个空翻”。
- **动作切分：**Groove → isolation → wave／pathway → hit → lock → release。强拍是动作完成点，反拍可用于小节奏。

## 3.8 Jazz Funk／Heels／时尚商业舞

- 重点是髋部重心、胸肋线条、肩部态度、手臂路径、头发和服装的延迟惯性，以及镜头与身体的距离控制。
- 可用侧压、髋部八字、胸腔波浪、肩部滚动、手臂绕线、交叉步、pivot、下沉再起、慢速延迟后快速释放。
- 高跟鞋编舞必须注意支撑脚与重心稳定；不要用无法站立的脚位组合。
- “性感”来自身体控制、线条、视线和镜头关系，不等于持续扭胯或强行贴近局部身体；动作应服务音乐、服装和人物气质。
- 镜头可贴身横移、绕到肩后、沿手臂／背部线条移动，再回到正面表演视线；但要避免整段只拍局部而丢失舞蹈结构。

## 3.9 Contemporary／Lyrical／现代舞

- 核心是重心失衡与恢复、螺旋、收缩与扩张、坠落与悬停感、地板动作、呼吸和空间路径。
- 可用 Contraction → Spiral → Fall → Floor → Recovery → Suspension → Hero 的连续逻辑。
- 每次坠落都必须写支撑、落点、如何缓冲、如何从地面恢复；不能瞬间从站立切成躺地。
- 现代舞动作不一定踩每个节拍，但必须回应乐句的张力与释放；不能用抽象的“自由舞动”替代真实身体路径。
- 镜头可随重心下降而降低，随恢复上升；利用地面机位、近身跟移和空间拉开表现身体重量。

## 3.10 芭蕾／古典技巧融合

- 芭蕾线条必须有支撑脚、重心、外开关系、躯干垂直与手臂位置之间的协调。
- Pirouette、Piqué、Attitude、Arabesque、Grand Jeté 等不能只写动作名；需要完整预备、发力、方向、技术峰值、落地与恢复。
- 可与古风服装、现代音乐融合，但不要把芭蕾技术误写成纯摆姿；身体必须有运动因果。

## 3.11 啦啦队／Cheer Dance

- 常见语法：高 V、低 V、T、斜线手臂、队形切换、kick、jump、落地锁定和笑容／舞台眼神。
- 手臂位置要明确、动作短促而清晰；脚下可以用 step-touch、侧并步、跳步和队形移动。
- 空中动作必须写起跳、空中姿态、最高点、落地、膝盖缓冲和手臂收束。
- 不要连续堆叠最大跳跃；用地面组合、强手臂动作和跳跃层次形成能量曲线。

## 3.12 双人／群舞／多人编排

- 先定义角色数量和每个人的空间关系；不要让镜面、影子或反射被误生成第二个角色。
- 双人舞：明确 lead/follow、接触点、支撑者、被引导者、接触动作进入与退出；不允许手臂突然穿透或身体互相融合。
- 群舞：明确队形（横排、V、斜线、圆弧、错列）、谁领拍、谁延迟、队形如何扩散／收拢、相机如何避开队形移动。
- 换人镜头可用一次 whip-pan，落点即新主角中心；不要长时间扫描人群。
- 接触式抬举需要明确支撑手、身体重心、进入路径、峰值与落地；不写“被托起”就让模型猜。

# 4. 舞蹈动作链：从动作名称到可执行运动

## 4.1 三层结构：持续层、动链层、微表情层

每段舞蹈至少包含三层：

1. **持续层（Groove / Base State）：**整段稳定存在的身体节奏，例如古风提沉呼吸、Idol 膝部轻弹、Hip-hop 重心下沉和弹性、Jazz Funk 髋部节奏。
2. **动链层（Action Chain）：**本段真正要完成的主要舞句，包含脚步、重心、骨盆、躯干、肩肘腕和手指动作路径。
3. **微表情层（Micro Accents）：**反拍头部轻点、眼神切换、眉眼反应、指尖释放、短暂直视镜头等。微表情不能抢走主舞句，也不能成为整段唯一动作。

三层必须互相配合：持续层不能变成没有变化的原地摇晃；动链层不能只剩手臂动作；微表情不能让人物持续眨眼或歪头而破坏身份稳定。

## 4.2 每条动作链十要素标准

每条 B／C 档动作链必须按以下逻辑设计：

1. **动作状态：**人物从什么姿态开始？是站立、低蹲、跪姿、弹跳中还是上一动作的恢复阶段？
2. **受力来源：**哪只脚承重？重心落在哪里？力量从地面、髋部、躯干还是手臂支撑产生？
3. **进入路径：**动作从哪个方向进入？支撑脚如何移动？骨盆如何预载？手臂从哪里开始？
4. **逐拍动力变化：**每拍／半拍发生什么连续变化？哪些动作是同一条链里的快速切分？
5. **技术峰值：**唯一最重要的可见结果是什么？例如双臂完全打开、旋转精准落面、身体波浪到达胸腔、跳跃到达最高点。
6. **惯性延续：**头发、裙摆、袖口、手腕、肩部和躯干怎样在主动作之后自然延续？
7. **回收顺序：**动作如何制动？先稳支撑脚还是先收手？身体如何回到可控状态？
8. **身体／服装物理：**衣料、长发、裙摆和袖片按真实惯性响应，不漂浮、不瞬间复位。
9. **镜头几何：**机位如何看见这个动作？是否需要全身？是否需要跟随、固定或在峰值到达构图？
10. **音乐触发：**动作何时启动、何时到主重拍、何时完成，是否有准确音频依据？

**禁止退化成“动作名＋形容词”。** 例如只写“完成一个 720° 旋转”是不合格的；H3 必须知道轴心、支撑脚、蓄力、旋转方向、角动量、完成时刻、目标方向、减速和回收。

## 4.3 动作设计五步逻辑

1. **建立支撑与预载：**明确哪只脚承重、重心去向、身体将向哪边运动。预载是动作的一部分，不是无意义等待。
2. **动力传递：**通常是支撑脚／重心 → 骨盆 → 胸腔／肋骨 → 肩 → 肘 → 腕 → 指尖；不用每次写全所有关节，但必须有可信动力源。
3. **到达主重拍：**指定一个主要可见结果；相机在同一时间到达对应构图。
4. **完成回收与制动：**吸收惯性、稳定支撑、回收手臂、相机同步减速；不能只写动作前半段。
5. **留下下一动作入口：**末态自然产生下一链的支撑脚、身体方向或动量，不突然重新站好。

## 4.4 入态／出态与动作链接

每条动作链都要有入态与出态。上一链出态必须能自然成为下一链入态。例如：

- 出态：右脚承重、左脚点地在前、右手收在胸前。
- 下一链入态：保持右脚承重，左脚沿侧向打开，右手沿胸前斜线释放。

H3 提示词中不需要写内部动作库编号，但应写出身体状态连接。**不要让每个动作都从标准站姿重新开始。**

## 4.5 时间窗容量：先判断时间，再塞动作

以下是初始估算，真实动作容量仍要根据 BPM、身体幅度、人物姿态、技术难度和镜头覆盖调整：

| 时间窗 | 合适内容 | 常见风险 |
|---|---|---|
| 0.3–0.6 秒 | 一个明确短促重拍：肘部切分、胸腔 hit、腕部翻转、单次定点 | 塞入完整复合舞句，结果动作丢失或变成乱动 |
| 0.6–1.2 秒 | 一条短链：重心交换→躯干转向→手臂释放 | 同时要求多个独立方向变化 |
| 1.2–2.5 秒 | 一条结构完整的复合舞句：动力传递＋主动作＋回收 | 罗列过多动作导致只完成其中一部分 |
| 2.5 秒以上 | 较长舞句、多动作链接、阶段性 Hero 技巧 | 没有中间目标导致原地重复或拖延 |

不应把“交叉手臂／侧弓步／两次肩击／180° 旋转／手腕绕环／双臂打开／回收”全部压进短短 2.6 秒。应该选一条主链，让它有可见的完成点；其余动作拆到下一窗口或删除。

## 4.6 动作密度参考，不作为死规则

- 甜系宅舞：约每 8 拍 2–3 条小链，可有 1–2 拍招牌动作／定格；脚下 Groove 持续。
- 快板古风：每 8 拍可有 4–6 个清晰动作变化，但它们应属于连续身韵链，不应变成孤立手势清单。
- 慢板古风：每 8 拍约 1–2 条完整主链，利用呼吸、眼神、袖摆余韵和重心延迟完成音乐表达。
- K-pop／Jazz Funk：采用主动作＋反拍细节＋位移／方向变化的组合；动作密度按音乐能量调节。
- **舞句层级的连接数量：**一段完整舞句通常由约 5–10 个彼此有因果关系的可见动作变化构成；它们可以是同一条 2–8 拍动作链里的连续子动作，也可以由两条短链连接。这里的数量是完整舞句的组织参考，不是要求每一拍都新增一个独立动作，更不意味着把 10 个复杂技巧塞进一个短时间窗。Hero 技巧按技术过程单独计算。
- **头眼是微节奏，不是装饰：**头部、眼神和指尖可以在反拍提供更细的节奏变化；头眼变化频率可高于大幅手臂动作，但要避免连续机械点头、频繁眨眼或不断歪头。
- Hero 技巧：单独给足时间，不为了动作数量压缩技术过程。

## 4.7 旋转预算与旋转完整性

- 整支普通 MV 默认控制完整 360° 转体数量，通常不超过两次；若歌曲和舞种确实需要更多，必须有明确理由和足够时间。
- 其他换面使用 quarter pivot、half turn、方向切换或视线转移，不必每次都完整转一圈。
- 旋转必须写支撑脚、旋转轴、发力方向、身体收紧／展开、完成方向、减速方式和落脚稳定。
- 不只写“spin fast”或“720° turn”；动作必须可被镜头捕捉并可判断是否完成。
- 摄影机 orbit 只在舞者本身旋转、或空间关系需要时使用；相机环绕速度与舞者旋转相位对应。不能围绕静止人物长时间空转。

## 4.8 跳跃／空中动作完整性

跳跃链：`Preparation → Load → Takeoff → Air Shape → Apex → Landing → Absorption → Recovery`。

必须写清：

- 起跳前哪只脚／双脚承重，膝髋怎样屈曲储能。
- 如何蹬地，身体向哪个方向离地，手臂是否协助起跳。
- 空中双腿和手臂的形态，身体是否转向。
- 最高点对应哪个音乐点，摄影机如何跟随。
- 落地顺序与落点，膝／髋如何吸收冲击，重心如何稳定。
- 落地后的动作如何继续，而不是瞬间变成摆拍姿势。

裙摆、袖片和长发因起跳产生滞后和回落，不要让服装独立漂浮。

## 4.9 地板动作完整性

进入地板、滚动、跪地、低位滑行和起身都必须写清路径：

- 从何种站姿进入，哪只脚先承重；
- 身体如何降低，手／膝／髋哪个部位先接近地面；
- 接触点如何安全承重，躯干如何旋转；
- 地面动作的方向与结束形态；
- 如何通过手掌／脚掌支撑恢复站姿；
- 镜头是否需要同步下降、贴地跟随，再随人物起身。

禁止只写“drops to the floor and rises smoothly”。

## 4.10 身体动力链的常见错误

| 生成症状 | 根本原因 | 修订方式 |
|---|---|---|
| 双臂抱在胸前反复摇晃 | 时间窗过载、动作无完成点、手臂没有释放路径 | 删除重复肩腕动作，指定一次交叉、切开、落点和收回；下一动作从释放状态开始 |
| 原地抖动 | 只有持续层，没有动链层；没有空间路径和支撑脚变化 | 加入一个明确脚步／重心变化和一个完整上身动作结果 |
| 交叉脚一直原地交叉 | 步法目标不清，没有明确开合、方向或承重交换 | 交叉一步后明确脚掌落点、重心交换，再打开侧步；不能连续循环交叉 |
| 动作很多但没有舞句 | 只列动作名，没有动力传递与因果 | 选一个主链，删除不服务它的动作，让动作由前一状态推导下一状态 |
| 旋转不完整／一直打转 | 轴线、支撑脚、完成方向和制动不明，窗口不足 | 拆出蓄力、旋转、定向、减速、回收；减少周围动作 |
| 跳起来但没有落地 | 只写 Takeoff／Apex，未写 Landing 和 Absorption | 明确双脚／单脚落地与膝髋缓冲，给出落地后的下一动作 |
| 手指畸形／多指 | 复杂手势、双手重叠、手势变化过多、特写过近 | 简化为单一手势；必要时只写简单 V 字；不要描述多种手指同时开合 |
| 舞者动作完成但镜头迟到 | 运镜是独立装饰，没有与动作共享时间 | 同一时间窗写相机启动／峰值构图／恢复；提前跑位，让画框先到 |

# 5. 摄影机语言：物理机位、运动路径与 H3 写法

## 5.1 摄影机第一原则：不要“命名效果”，要定义物理事实

H3 对抽象角度词容易平均化处理。不要只写：

- `Extreme low angle.`
- `Dutch angle.`
- `Dynamic orbit.`
- `Close-up cinematic camera.`

应写出相机实际位于哪里、镜头高度、人物距离、朝向、运动路径，以及该位置自然产生什么画面几何。

**NO DEGREE LAW（摄影机角度描述纪律）：**

- 普通镜头不要依赖“低角度 30°”“仰拍 15°”“斜俯 45°”这类角度数字。
- 改用物理关系：摄影机贴近地板、位于人物膝／腰／胸／眼睛高度、安装在柜顶、位于人物肩后、贴近地面沿侧面移动、从人物正上方垂直向下等。
- 用户明确指定的 `Extreme Overhead 90°` 是专用预设例外：必须是真正垂直地面向下的正上方机位，不是普通高角度斜俯拍。
- 数字角度不是 H3 摄影提示的主要控制变量；真实物理位置、距离、光轴和空间关系才是。

## 5.2 每个 Shot 的八要素物理结构

每个 Shot 都按以下结构设计，不必写成表格，但信息应完整：

1. **Camera Physical Placement：**相机实际位于人物前方、侧前方、背后、脚边、肩后、桌沿、地板、天花板或其他具体位置。
2. **Height：**镜头离地高度或相对人物身体的位置。
3. **Distance：**与人物的真实拍摄距离；需要贴身感时，必须说明相机与人物保持近距离，而不是只说“close cinematic shot”。
4. **Optical Axis：**镜头朝向人物哪一部分、是否正对、沿人物运动方向还是向上／向下。
5. **Spatial Relation：**人物在镜头前、后、侧方或从镜头旁经过，前景／后景如何形成层次。
6. **Physical Result：**该机位自然看到什么，例如近处地面被放大、人物从镜头上方俯视、袖片扫过前景、脸部保持可读。
7. **Movement Response：**人物起步、跳跃、转身或下降时，相机如何沿真实路径跟随、平移、升降或保持固定。
8. **Camera Lock：**相机保持在哪个位置或何时停止；拍摄设备不得出现在画面中。

## 5.3 常用物理机位

| 机位类型 | 物理定义 | 适用场景 | 注意事项 |
|---|---|---|---|
| 眼平近景 | 镜头位于人物眼睛附近高度，正面或三分之四正面 | 人物肖像、表情、直视镜头 | 不要无理由长时间保持静止 |
| 胸高／腰高跟拍 | 镜头处于人物胸／腰附近，沿其运动方向平行移动 | 中景舞蹈、髋部与上身动作 | 脚步被裁掉时需切回全身 |
| 膝位跟拍 | 镜头位于膝附近，平行跟随步伐 | 脚步、Kick、低位身法 | 保持真实脚底与地面关系 |
| 地板极低仰拍 | 摄影机实体平放在地板或靠近地面，镜头离地很低并朝上看人物 | 贴地强透视、人物逼近镜头、踢腿向镜头 | 不是腰高机位轻微抬头；要明确地面透视与人物高于镜头 |
| 贴地平拍 | 摄影机位于地面附近，光轴沿地面水平 | 低位滑步、鞋／脚接触、地面动作 | 不要误成仰拍 |
| 高机位斜俯 | 摄影机放在高处，朝人物和地面看下去 | 空间关系、队形和位置揭示 | 不等于真正 90° overhead |
| True 90° Overhead | 摄影机在人物正上方，光轴垂直地面向下 | 俯视构图、倒影、几何舞步、指定俯视预设 | 严格向下；不允许斜俯退化；人物仍要有正常比例 |
| 侧面机位 | 镜头处于人物左／右侧，沿运动路径观察 | 身段、侧向移动、转身、腿线 | 明确人物朝向和相机移动方向 |
| 肩后机位 | 摄影机位于人物肩后，越过肩线观察前方或面部侧线 | 情绪、舞蹈中的方向揭示、视线引导 | 不要在没有第二人物的情况下凭空补出对面的人 |
| 背后跟随 | 摄影机在人物背后，沿同一方向移动 | 进入空间、连续走位、转身前准备 | 要保证主体仍然可辨认，不让镜头长期只看到背部 |
| POV | 摄影机就是角色眼睛所在的位置 | 被窝内部、箱内、桌面下、人物观察视角 | 不等于出现摄影设备；如涉及对象必须明确在画外或不出现 |
| 前景遮挡机位 | 摄影机在已有前景物后方或旁边拍摄，让真实物体扫过画面 | 袖、纱、门框、家具边缘遮挡转场 | 只能使用已存在或明确允许的前景物 |

## 5.4 极限仰拍的物理写法

当需要强烈的地面透视：

- 相机可设为一台放在舞者脚边地板上的小型摄影机，镜头离地约 5–15 cm，向上观察人物。
- 说明地面靠近镜头、人物站在镜头上方、人物靠近时因真实透视自然放大；人物抬膝或踢腿靠近镜头时，近处肢体自然产生透视变化。
- 固定机位时明确相机不移动，所有尺度变化来自人物的真实靠近／远离，不来自数字变焦。
- 必要时补充简短退化锁：不是眼平镜头向上倾斜；不是腰高低机位；不是后期裁切；不是数字变焦；相机和支架不入画。

## 5.5 Extreme Overhead 90° 极限俯拍预设

用户指定该预设时默认：

- 摄影机位于人物正上方，光轴严格垂直地面、向下；不是普通高机位斜俯。
- 人物是画面主要主体，构图紧凑，头部、上身、手部和膝部可按要求完整进入画面；不因过远而把人物变成地面上的小点。
- 脸朝向镜头时，人物抬眼进入镜头；地面成为主要空间平面。
- 透视来自相机与人物的真实距离，不通过鱼眼、拉伸、压缩或数字变形实现。
- 不改变用户提供的姿势；该预设只定义摄影机位置和构图，不自动重设计动作。

## 5.6 贴身环绕与近距离运镜

“贴身环绕”必须真正改变相机相对人物的位置，不能在房间远处绕一个大圈：

- 相机从人物右前侧近距离开始，沿人物肩线或腰线外侧走短弧线，到正前方或左前侧。
- 路径要与人物动作有关系：伸手时沿手臂方向移动，转身时绕过肩线，裙摆展开时绕到侧后方，回眸时及时回到可读面部的位置。
- 距离变化有原因：人物靠近镜头时相机可后撤让出空间；人物下沉时相机下降；人物回身时相机通过侧向移动重新取得面部。
- 时近时远、速度有起伏，不能匀速绕拍完整一圈。
- 任何近身运动都必须保持身份、脸部几何和身体比例自然；不靠夸张广角导致脸被拉扯。

## 5.7 主要镜头运动路径

| 运动 | 物理动作描述 | 最适合的舞蹈触发 |
|---|---|---|
| Push In | 摄影机真实向人物靠近 | 动作逐渐聚焦、表情峰值、舞句进入主重拍 |
| Pull Back | 摄影机真实后退、扩大空间 | 队形展开、跳跃落地、舞者向外打开 |
| Truck Left/Right | 摄影机平行横移 | 侧向步伐、队形横移、横向 Skater-hop |
| Arc Move | 摄影机沿人物外侧短弧线移动 | 转身、开胸、身体波浪、从侧面揭示正面 |
| Orbit | 摄影机围绕人物移动 | 人物本身旋转或舞句需要强烈空间环绕；速度与人物转动相位对应 |
| Pedestal Down/Up | 摄影机实体下降／上升 | 人物下蹲、地板动作、起身、跳跃 |
| Pan / Tilt | 机身原位水平／垂直转动 | 手臂路线、视线、动作方向或环境揭示 |
| Whip Pan | 快速甩镜并以运动模糊完成转场 | 主角轮换、场景硬切、强拍动作释放 |
| Handheld Reactive | 轻微、受控、有人操作感的动态响应 | 亲密、俏皮、醉酒感或临场感 |
| Static Plant | 相机真正固定，让舞者向镜头运动 | 踢腿、手臂／脚步冲向镜头、关键直视时刻 |
| Focus Pull | 改变真实焦点，不移动相机位置 | 从手／袖／前景转回面部或全身主体 |
| Snap Zoom | 突然改变镜头焦距／画面放大感 | 极短重拍强调；须谨慎，不能代替真实机位运动 |
| Reactive／Drunken Camera | 摄影机先观察、略有滞后、短暂过冲、修正后重新捕捉主体；可带轻微垂直起伏和短暂水平倾斜 | 俏皮、醉意、主观失衡、临场感；人物本身仍保持稳定与可读 |

尽量先用实际空间移动表达镜头变化。Snap Zoom 可以作为少量重音效果，不应成为每段的默认镜头设计。

### 特殊：醉酒式／反应式摄影机

这是摄影机的主观失衡，不是舞者身体失控。运动链为 `observe → react late → overshoot → correct → reacquire`：先观察人物动作，随后略晚半拍响应；相机短暂移动过头，再平滑修正并重新捕捉主体。可伴随轻微上下起伏和短促 roll，但水平倾斜只短暂出现，随后回正；禁止全程持续滚转或剧烈乱抖。适合俏皮、微醺、记忆感或喜剧性 MV，不适合所有古风慢板。

### 长镜头的内部变化

- 一镜到底可通过真实机位移动、景别变化和高度变化制造“隐性切镜”。
- 古风长舞可以用高度层组织：地面／跪姿 → 起身链 → 站立舞句；一次完整起身本身就是镜头节奏变化。
- 对 8–12 秒左右的长舞段，可考虑每次只改变一个主要空间变量，例如横移一个位置或改变人物朝向，不要同时要求大幅位移和复杂转身。
- 甩发、转体、袖片遮挡或人物经过前景可成为软切点；必须依赖当前画面真实存在的元素。
- 开头和结尾可形成静与爆的对比，但绝对静止要有明确音乐位置和时长；不能把静止当成 H3 自动填充空白的默认状态。

## 5.8 运镜与动作 1:1 同步铁律

**一套时间码、两条同步运动轨迹、同一组动作峰值。**

六项要求：

1. **同时启动：**人物开始一个动作时，相机在同一触发时刻开始对应响应；如果相机需要提前跑位，必须写在该动作的预备阶段。
2. **同步运动：**人物移动、伸手、转体、跳跃或下降时，相机沿真实可执行路径跟随或改变机位。
3. **峰值同步：**手指伸展、旋转到位、脚步落地、双臂打开等主要动作重音，与构图峰值同时到达。
4. **同步恢复：**人物收势、回中或反向移动时，相机同步减速、回移或改变方向。
5. **连续衔接：**前一动作的恢复直接进入下一动作，不插入无意义延迟运镜。
6. **绝对时间码：**身体动作与相机运动在同一局部时间轴上写出起止时间；不要给相机另造一套独立、模糊的时间。

### 画框先于动作到位

- 对大幅度 Hero 定点、V 臂、跳跃落点或队形展开，相机应在主要动作到来前的预备段先跑位，让构图先于动作到位。
- 不要等动作已经做完才突然推近或绕到另一侧。
- 如果相机移动应该在动作释放时开始，就写明从预备／释放拍同步启动；动作峰值时相机已进入目标构图。

### 动作到相机的常用映射

| 人物动作 | 相机响应 |
|---|---|
| 单人定点 Solo | Static 起始，随后缓慢 Push In |
| 人物横向交叉步 | 平行 Truck，与人物步速接近 |
| 人物向镜头踢腿／冲击 | 相机 Plant 固定，让动作走进镜头 |
| 全身下蹲 | 相机同步 Pedestal Down |
| 下蹲后起身 | 相机随恢复 Pedestal Up |
| 跳跃 | 相机在起跳时上升或后撤，最高点构图清晰，落地时同步稳定 |
| 旋转 | 相机沿短弧线或匹配相位环绕，不能超过人物速度造成无意义绕拍 |
| 手臂横向大展开 | 相机横移或轻微后撤，完整保留手臂线条 |
| 群舞队形展开 | 相机 Pull Back，速度略快于队形展开以提前呈现完整图形 |
| 队形平移 | 相机 Truck 同速跟随，保持队形主轴 |
| 换主角 | 一次清楚 Whip Pan，落点即新主角构图中心 |
| 终点定格 | 相机逐渐减速至 Static，作为结束信号 |

## 5.9 Shot 尺度与信息分工

| 景别 | 主要信息 | 使用规则 |
|---|---|---|
| Extreme Wide／Wide | 空间、队形、人物与环境关系 | 不要让人物小到看不清舞步；宽景要有队形或空间目的 |
| Full Body | 完整脚步、重心、跳跃、转身和整体动作 | 重要舞步、落地和动作链必须有足够全身镜头 |
| Medium Full／膝上 | 上身、髋部和大部分舞蹈动作 | 可用于身体波浪、Jazz Funk、手臂路径 |
| Medium | 上半身和手臂关系 | 不应替代整段舞蹈覆盖 |
| Close-up | 面部、情绪、眼神、手部细节 | 应短而有目的，随后回到舞蹈信息 |
| Extreme Close-up | 手指、饰品、眼睛、布料纹理 | 作为插镜和视觉钩子；不应占用连续舞蹈主体时间 |

原则：动作越依赖脚步和支撑，镜头越要给足全身；情绪／微表情／服装细节才进入近景。不能为了“高级感”把所有舞步拍成腰部以上，导致脚步和重心完全不可见。

## 5.10 一镜到底与多镜头剪辑

- **多镜头剪辑：**每个 Shot 都有自己的本地起止时间、镜头位置、动作内容和切入理由；使用明确 `CUT`，不要把多镜头误写成一条连续 Camera Path。
- **一镜到底：**用真实机位移动、景别变化、前景遮挡、焦点转移、Whip Pan 和高度变化制造镜头内部节奏。若需要从中景快速变为极宽景，必须给出可执行的移动路径和完成时间，不能写成数字裁切。
- 每个景别应有足够辨识时间；实测录舞镜头的常用基线是单个景别通常至少约 1.5 秒，除非它明确是节拍插镜、遮挡帧或短促细节。极短插镜只承担单一信息点。
- 手部／眼睛／饰品／衣料等细节插镜可短至约 0.3–0.7 秒；若要观众读清具体细节，可延长至约 0.5–1 秒，但不能让连续 2–3 秒的静物特写挤占主要舞蹈时间。
- 动作峰值前先构图；不要在动作峰值时突然开始移动相机，把关键动作拍丢。
- 让人物动作和相机的速度曲线有起伏：启动、加速、稳定、释放、减速，而不是每段匀速推进或环绕。

# 6. MV 剪辑、转场与视觉连续性

## 6.1 转场不是特效清单

每个转场只选择一个主要机制，并说明它为什么发生：

- **Match on Action：**上一镜动作未结束，下一镜从同一方向／相位继续；最适合舞蹈和连续动作。
- **Shape Match：**圆形、X 形、V 形、臂线、窗框等形状匹配；例如胸前心形切到圆形道具，但不得让道具凭空出现。
- **Direction Match：**人物或前景沿同一方向运动，下一镜继承方向，不一定继承姿势。
- **Foreground Wipe：**已有的袖、发、纱、门框或家具边缘短暂遮挡镜头，切换后揭示新构图。
- **Whip Pan：**在动作释放或音乐重音时快速甩镜；用于换场、转主角或能量突变。
- **Focus Match：**从前景细节拉焦至人物，或从人物转移至环境，不靠凭空加道具。
- **Reflection Match：**利用已存在的水面／镜面倒影与实体匹配；反射必须是同一个人的物理反射，不生成第二个独立人物。
- **Rotation Phase Match：**人物在旋转中切镜，下一镜从同方向、近似速度和相同旋转相位继续；是跨场景连接旋转的有效方式。
- **Hard Cut on Beat：**以音乐重拍、动作完成点或乐句边界直接切镜；舞蹈能量跨切延续。
- **Soft Dissolve：**只在亲密、回忆、接触或情绪段落少量使用；避免大段叠化造成重影／双人幻觉。
- **Flash／White Flash：**少量用于高潮边界，必须有音乐触发和视觉目的，不能每段都闪。

## 6.2 段间衔接要点

- H3 每段独立生成，不应写“继续上一段视频中的所有动作”，除非明确使用视频参考且平台支持连续引用。
- 后期剪辑可以让上一段末尾的手臂方向、旋转相位、遮挡物、圆形轮廓或脚步运动与下一段开头匹配。
- 每段必须自包含：人物、服装、场景、参考图职责、音频、动作、镜头和结束状态均在本段说明。
- 前后段可以视觉连续，但不要强制 H3 下一段复刻上一段最后一帧；有时动作方向匹配就足够。
- 不要为了匹配让人物在每段末尾都僵硬定格；可以在自然动作释放时切段。

## 6.3 段间转场表的写法

在完整 MV MD 中另设 `Segment-to-Segment Transition Map`：

| 边界 | 上一段结尾 | 下一段开头 | 转场机制 | 后期执行要点 |
|---|---|---|---|---|
| SEG01→SEG02 | 某一动作方向／视觉形状 | 相似方向／形状 | Match on Action | 说明剪辑点、速度和是否需要硬切 |

每一行只写一个主机制，不要同时堆叠旋转、闪白、叠化、遮挡、粒子和缩放。

## 6.4 高潮剪辑

- 可以在高潮主重拍之前使用少量 0.07–0.25 秒快闪定格，但必须落在音乐节奏中并服务能量累积。
- 快闪完成后必须回到完整可读的舞蹈画面，让观众看见动作兑现。
- 旋转、跳跃、队形扩张、袖舞和镜头运动可以共同形成高潮，但一个段落只选主要高潮机制，避免全部挤在同一瞬间。
- Final Chorus 不应机械复制第一次副歌；使用动作变奏、相机位置变化、反向线路或更完整的 Hero 组合升级。

## 6.5 终段设计

- 终段根据歌曲尾音决定动作收束速度；动作可以逐层缩小，但不应在音乐结束前过早僵住。
- 最后一个动作必须包含明确完成点与身体稳定；衣料和头发可保留自然惯性。
- 镜头在人物终点动作完成时缓停，或在尾音内有目的地拉开；音轨结束时间与视频结束时间准确对应。
- 不要在最后一秒无故切一个静物或背景全景，除非创意方案明确要求。

# 7. 古风与现代 MV 的镜头策略差异

## 7.1 古风 MV：身韵、衣料与空间关系

古风镜头要让观众看清“气如何经过身体”，也要看到衣袖和裙摆如何回应动作：

- 慢板：眼神先行、手腕细节、躯干提沉、近距离弧线和短暂衣料特写。
- 快板：穿掌、翻腕、盖步、点步、快速转向、袖势扩张和动作硬切。
- 技巧段：全身镜头展示支撑、轴线、动作峰值和落地；摄影机不要用过多遮挡掩盖技术细节。
- 情绪段：肩后、侧前、回眸、空置座位、窗光、纱幔和反射可提供内在情绪，但不能让人物停下来只看风景。
- 空间段：通过前景纱、窗格、柱廊、地面反光、空间高度和景深层次揭示环境；只使用参考图真实存在的元素。
- 俯拍是构图选择，不是古风默认机位；严格 90° overhead 只在明确需要的 Shot 使用。

## 7.2 现代 MV：身体动势、节拍与镜头能量

- 现代舞蹈强调 Groove、脚步、髋部／胸肋隔离、动作重音和节拍变化。
- 现代商业 MV 可以更多使用近身横移、短弧线、低位跟拍、动作甩镜和跳跃落地同步。
- 重要副歌给全身和宽构图，细节镜头用来强化表情、手势或服装质感，不要让剪辑把舞句切碎。
- J-pop／Idol 的招牌动作要有识别度和表演视线；K-pop 重视动作线条、队形和重拍；Hip-hop／Street 重视 Groove 与重量；Jazz Funk 重视髋部、胸腔、手臂线条与眼神态度。
- 夏日／派对／校园等风格只作为视觉定位，不能无缘无故新增海滩、泳池、烟花、舞台、观众或其他场景。

## 7.3 贴身与福利式构图的专业边界

- 近身镜头首先服务人物动作、服装摆动、转身线路和画面节奏；不能因为局部近景而丢失舞蹈叙事。
- 镜头沿真实摄影机路径移动，近景和全身之间需要有动机的转换。
- 不要通过不合理的身体变形、透视拉伸或强迫姿势制造视觉强调；人物身份与比例应稳定。
- 若设计裙摆、袖摆或发丝的动态展示，应由跳跃、旋转、步伐和惯性自然产生，不额外改变衣物结构或添加衣物。
- 对镜头表达的限制以用户项目要求、人物年龄、服装设定和平台规范为准；不把不适宜的对象变成身体展示镜头。

# 8. H3 提示词工程规范

## 8.1 提示词的语言分工

- **MD 说明区：**中文，用来写版本记录、制作方向、参考图职责、时间表、段落摘要、转场表、复核结论和检查清单。
- **H3 可复制提示词代码块：**原则上使用完整英文指令；避免中英夹杂导致模型误读。
- **原始对白：**若存在 Spoken，保留用户提供的原语言，并按项目要求使用结构化标签，例如 `<d>[Japanese] ...</d>`；不要翻译成英文后当成真实对白。
- **内部动作库编号：**只用于导演内部规划和选择，最终英文提示词不出现 A1、C3、K17 等编号或“动作库第几条”。必须把动作转写成自然、具体、可执行的英文动作描述。

## 8.2 H3 多模态标记

按实际素材使用并正确写入：

- `<Picture 1>`、`<Picture 2>`、`<Picture 3>`、`<Picture 4>`：引用实际图片输入。
- `<Audio 1>`：引用当前片段对应的音频切片。
- `<Subject 1>`：定义当前可见主角；多人时分别定义 Subject 2、Subject 3，并锁定人物数量与身份。
- `subject_definitions:`：主体定义区。写清楚哪一张图负责身份；若不需要重新描述外貌，直接声明精确保留图像身份与服装。
- `integrated_multimodal_description:`：整合本段画面、动作、摄影、参考图和时间线。
- `overall_soundscape:`：声明本段声音来源、保真与禁止添加内容。
- `non_diegetic_music:`：声明音乐是否由 Audio 1 唯一提供，是否允许额外音乐或音效。

标签必须使用 H3 接受的准确拼写和括号形式。不要自行改为普通方括号或随意替代标签。

## 8.3 Audio 1 的权威规则

- 每个 Segment 只输入对应的 Audio 1 音频切片；局部时间从 `00:00.000` 重新开始。
- 总片时间（GLOBAL）只用于 MD 的总表、歌词／节拍索引和剪辑定位；实际 H3 段落内的 Shot 时间使用 LOCAL。
- 视频输出时长与对应切片一致；不要擅自延长、缩短、补拍、重启或循环音乐。
- `overall_soundscape` 和 `non_diegetic_music` 应声明 Audio 1 是唯一原声来源；不额外添加 BGM、替换人声、对白、掌声、脚步声或环境声，除非用户明确要求。
- 有演唱但没有要求口型时，注明 sung vocals remain part of soundtrack；不强行做逐字唱口型。
- 真实 Spoken 才做口型；不能把歌声错当成 Spoken。
- 如使用 cuts manifest，必须以它为切片边界、时长、原曲偏移和 Spoken 时间码的权威来源。

## 8.4 时间码规范

推荐写法：`00:00.000–00:02.696`。

每段说明：

- Global 起止时间；
- Local 时长；
- 对应 Audio 1 文件名；
- 该段音乐／歌词／器乐位置；
- 每个 Shot 的 Local 起止时间；
- 动作链完成点与相机峰值；
- 片尾转场钩子。

禁止：

- 混用 Global 和 Local；
- 使用没有对应音频的想象时间码；
- 只写“on the beat”而不说明动作大致窗口；
- 对未提供的音频细节伪造精确 downbeat；
- 在未测量的情况下编造逐音节、逐 mora 或逐 phoneme 时间码。

## 8.5 Spoken 与舞蹈的分离

如果片段有 Spoken：

- `<Subject 1> (S1)` 必须是稳定的可见说话人身份。
- 原文以 `<d>[Language] 原文</d>` 写入对应时间窗。
- 发声期间优先稳定正面面部近景，嘴唇、下颌和下巴无遮挡；避免推近、绕拍、拉焦、切离或手势遮脸。
- 手势尽量在台词前预先定位，放在下巴以下；发声窗口内保持稳定。
- 句尾自然闭唇；静默时只做眼神、眉部、呼吸反应。
- 省略号或文本停顿不自动等于发声；只对 Audio 1 中实际发出的音做口型。
- 不要让复杂舞蹈和发声口型在同一时间争夺脸部与身体动作；只有明确的闭唇静默窗口才安排短舞步。
- 演唱歌词仍然属于 Audio 1，不强制逐字口型。

如果是纯舞蹈 MV：明确说明 no dialogue, no spoken words, no deliberate singing lip-sync；嘴部只保留自然呼吸与表情。

## 8.6 每段独立任务规则

每个 H3 片段是独立生成：

- 不写“继续上一段的同一视频”，除非本项目明确有可用 Video Reference 并已定义职责。
- 重复必要的角色锁、服装锁、场景锁、参考图分工、音频规则、画幅与片段时长。
- 本段镜头、动作和视觉构图必须能单独成立。
- 段间转场放在独立的剪辑表中，不用一条含糊的全片指令代替每段的完整动作。
- 若同一个背景必须跨段一致，每段都要重复环境锁定关键句。

## 8.7 自包含程度

“自包含”不是把全片所有设定粘贴到每段，而是把当前段完成任务所需的固定信息写全：

- 当前 Subject 的身份和数量；
- Picture 职责与视觉优先级；
- 当前地点和不能改变的环境；
- 当前 Audio 1 时长、局部时间、声音规则；
- 本段舞蹈风格、持续层、主要动链；
- 每个 Shot 的动作与摄影机物理关系；
- 结尾完成状态或剪辑钩子。

避免无关的角色背景、其他段落时间码、动作库编号和没有帮助的禁止项。

# 9. 最近 MV 的标准 Markdown 交付格式

本节是必须保留的交付模板。以后制作 H3 舞蹈 MV，默认输出**单一完整 Markdown 文件**，不拆散为多个不相关文件，不只给补丁，不用“以下略”代替完整分段提示词。

## 9.1 文件结构顺序

标准文件按以下顺序组织：

1. **总标题：**作品名称＋H3 Commercial MV Prompt Pack＋Revision。
2. **版本信息：**Rev、来源音频、时间权威、总时长、段数、画幅、BPM、Beat、Bar、Phrase、First Downbeat。
3. **修订记录：**写清本版改了什么、保留什么、撤回什么；不得把未修改的内容冒充重写。
4. **来源分配表：**若整合多个版本，明确每段采用哪个版本、哪部分独立重写。
5. **全片方向：**MV 创意、核心概念、风格与能量曲线。
6. **图片素材职责表：**逐张明确 Picture 1–N 的唯一职责。
7. **全片视觉圣经与制作纪律：**人物、服装、环境、道具、摄影、舞蹈、音频等。
8. **音频分段索引：**Global 时间、Local 时长、Audio 文件名、音乐段落／歌词定位、舞蹈重点。
9. **H3 Copy-Ready Prompts：**所有独立 Segment，每段都提供完整英文代码块。
10. **Segment-to-Segment Transition Map：**全部相邻段落的剪辑钩子。
11. **必要的 Spoken／舞蹈时间审计：**若有对白、口型或特殊动作时间窗才需要。
12. **Pre-Generation Checklist：**生成前检查。
13. **Post-Generation Review／Failure Diagnostics：**生成后如何判断与修订。

每段外部摘要建议包括：

## 9.5 代码块的语言纪律

- H3 提示词代码块统一用英文，避免把中文导演注释夹在英文动作指令里。

- 真实 Spoken 台词保留原语言；只把台词放入指定结构化标签。
- 动作库代号、内部参考视频名称、讨论过程、修订理由不要进入 H3 执行正文。
- “镜头角度”不要只写术语，按第五章的物理机位结构改写。
- “性感、可爱、仙气、力量感、商业感”等形容词必须落实为具体的动作、表情、身体状态或摄影行为，不可只保留抽象评价。

# 10. 全片舞蹈与镜头的分段组织

## 10.1 片段长度

H3 单次生成建议控制在约 10–15 秒范围内，优先服从当前任务和平台允许长度。近期 Rev.8.7 的实践是 18 个独立片段，每段约 11–14 秒，单段单独输入对应的 Audio 1。

切段目标：

- 尽量在乐句结束、动作收点或自然动作释放处切分。
- 避免把一个关键技术动作切成前后两个互不完整的片段。
- 若必须跨段，需明确剪辑对接方式；新段仍有自己的完整起始姿态和动作入口。
- 不为了段数均匀而破坏音乐结构；某段略长／略短应由音乐和 H3 可执行容量决定。

## 10.2 每段的设计卡

每个段落在写 Prompt 前先在内部建立：

| 维度 | 需要确定的内容 |
|---|---|
| 音乐功能 | Intro／主歌／副歌／桥段／尾奏等 |
| 主要能量 | 低、中、高、爆发、回落 |
| 舞种 | 主舞种＋可选融合 |
| Groove | 本段持续层是什么 |
| 主动作链 | 一条主要舞句及其入态／出态 |
| 辅助链 | 是否需要一条短链或微表情 |
| Hero | 是否存在跳跃、旋转、地板技巧或招牌动作 |
| 空间路线 | 原地／横移／斜向／前后／圆弧／高度变化 |
| 主镜头语法 | 近身环绕／横移／贴地／肩后／Overhead／宽景等 |
| Shot 结构 | 是一镜到底还是明确多镜头 |
| 结尾钩子 | 方向、形状、视线、遮挡或动作相位 |

## 10.3 舞蹈／插镜比例

近期现代商业 MV 的实测方向是“舞蹈主导、叙事插镜短促”：

- 除 Spoken 发声、必要静默反应和极短道具信息外，大部分可用音乐时间应让人物保持节拍运动。
- 多数非 Spoken 乐句包含一个可辨认的 4–8 拍舞句，必要时接一条短链。
- 可以短暂插入脸部、眼睛、手部、饰品或道具特写，但插镜要服务节奏和视觉钩子，随后回到完整舞蹈。
- 近景／道具镜头不能长时间挤占舞蹈主体时段；脚步、落地、旋转和重心变化要有足够画面时间。
- 对古风慢板、情绪肖像 MV 或用户明确要求的剧情型段落，比例可以降低，但必须有清楚理由。

## 10.4 防止段落同质化

相邻段落尽量避免连续重复：

- 同一景别、同一人物画面位置、同一摄影机起始点；
- 同一动作链、同一手势、同一脚步方向；
- 同样的正面缓推或绕人物一圈；
- 同样的静止开场和站立结束；
- 同样的道具插镜／遮挡方式。

变化不等于每段换一套风格。全片必须有统一的视觉世界，但通过舞蹈动作族、景别、相机路径和空间方向变化保持新鲜度。

# 11. 常用舞蹈链与镜头配合范式

以下是可供导演组合的动作范式，不是完整动作库替代品。真正输出 H3 时，应根据动作库的最新可靠链选择并转写为自然英文。

## 11.1 甜系 Idol 组合范式

**持续层：**小幅膝弹＋脚掌重心转换。  
**短链 A：**胸前 X 交叉 → 双臂水平展开 → 手腕回收。  
**短链 B：**交叉步 → 脚尖侧点 → 同侧胯部轻 pop → 回中。  
**招牌动作：**猫爪框脸／拼心／V 臂／简单 V 字手势。  
**收尾：**并脚小跳 → 膝盖吸收 → 手臂落下，保持轻微回弹。

摄影：从中全身平行横移开始，在手势峰值前轻微推进；脚步转换时保持全身可读；最后用面部近景或动作匹配切结束。

## 11.2 现代高能舞组合范式

**持续层：**下沉 Groove、膝部弹性、躯干松弛。  
**主链：**step-cross → hip figure-eight → torso wave → diagonal arm drive → side press → skater-hop。  
**重音：**一次胸腔 hit 或双臂强力打开。  
**收尾：**落地吸收 → 转向 → 动能继续，不重新站定。

摄影：横向 Truck 与脚步同速；在主重拍前提前跑位；跳跃时镜头随身体上升，落地时同步稳定。

## 11.3 古风袖舞组合范式

**持续层：**提沉呼吸＋虚实重心变化。  
**主链：**盖步承重 → 腰胯拧转 → 胸腔延伸 → 双臂云手 → 穿掌翻腕 → 袖片外展 → 眼神回收。  
**重音：**袖线展开或身体轴转到位。  
**收尾：**脚下稳定、袖片延迟回落，下一链从手腕／重心方向接入。

摄影：先以侧前方近身视角读取手臂线条，袖片扩张时相机沿短弧线移动；主重拍给全身或中全身，确保脚下承重可见。

## 11.4 古风快速舞句组合范式

**持续层：**短促提沉与快节奏点步。  
**主链：**点步换重心 → 双手穿掌 → 交替翻腕 → 小幅 pivot → 袖臂斜线打开 → 立即回收。  
**重音：**转向完成或双臂定线。  
**收尾：**避免多圈旋转；用眼神和袖摆余韵完成句尾。

摄影：短横移跟随脚步，在主手势达到峰值时短暂稳定构图；切镜落在动作完成点。

## 11.5 情绪现代舞组合范式

**持续层：**呼吸与重心摆荡。  
**主链：**胸腔收缩 → 脊柱螺旋 → 重心失衡 → 手／膝支撑进入地面 → 沿地面转向 → 通过手掌与脚掌恢复站立。  
**重音：**坠落或重新站起的完成点。  
**收尾：**恢复后不立刻冻结，保留呼吸和张力。

摄影：相机随着坠落同步下降，贴地跟随身体路径，再随恢复上升；确保地面动作的接触点可读。

## 11.6 时尚 Jazz Funk 组合范式

**持续层：**髋部八字和胸肋微型隔离。  
**主链：**侧向 step-touch → 骨盆侧压 → 胸腔 wave → 肩部滚动 → 手臂交叉绕线 → pivot 换面。  
**重音：**肩／胸腔 hit 和眼神直视。  
**收尾：**手臂沿身体线条回收，重心带向下一步。

摄影：近距离侧前方弧移，随后平行跟拍横向位移；避免只拍脸或只拍局部身体。

# 12. 生成前、生成后与修订规则

## 12.1 生成前总检查（每段都要过）

- [ ] **音乐准确：**当前 Audio 1 切片、时长、Global／Local 时间、BPM 和 downbeat 依据正确。
- [ ] **参考图准确：**Picture 1–N 的职责明确，冲突优先级写清楚。
- [ ] **人物锁定：**身份、脸部几何、服装、发型、配饰和人数一致。
- [ ] **环境锁定：**空间结构、墙面、地面、门窗、家具、色彩、光线无无故变化。
- [ ] **道具账本：**没有新增道具、复制道具、替换道具或不连续道具。
- [ ] **舞种准确：**动作语法符合风格，不把古风与现代动作混为一谈。
- [ ] **动作链完整：**每个窗口都有起势、动力、主结果、回收和下一链入口。
- [ ] **容量准确：**动作难度与时间窗相适应，没有把多个 Hero 动作挤在一起。
- [ ] **脚步可读：**关键步法、支撑脚、重心和落地有合适景别。
- [ ] **运镜物理化：**机位位置、距离、光轴、空间关系和运动路线明确。
- [ ] **同步运镜：**人物和相机共用时间码，动作峰值与构图峰值一致。
- [ ] **剪辑有理由：**镜头切换、插镜和转场由音乐／动作／视觉母题触发。
- [ ] **段落自包含：**单独复制本段就能理解，不引用“同上”和前文。
- [ ] **提示词语言：**H3 代码块为英文；无内部动作编号；对白原文正确。
- [ ] **声音保真：**原声不重启、不改速、不叠加不必要音效；歌唱不被错误当成 Spoken。
- [ ] **没有机械错误：**无重复摇晃、原地打转、机械交叉脚、无意义慢走或整段僵硬定格。

## 12.2 生成后分项评估

每个片段建议按 1–5 分审查：

| 维度 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 人物一致性 | 明显换脸／换装 | 大体一致但局部漂移 | 身份、脸、衣服稳定 |
| 场景一致性 | 背景重建／乱加物件 | 主要结构在但有变化 | 结构、色彩、光线稳定 |
| 节奏同步 | 动作错拍／拖慢 | 大体匹配但峰值不准 | 起势、峰值、回收贴合音乐 |
| 动作完整性 | 摆姿／重复摇晃 | 部分动作完整 | 主要舞句完整且自然 |
| 动力学可信度 | 脚滑、漂浮、穿模 | 偶有不稳 | 支撑、重心、惯性自然 |
| 舞种风格 | 风格混乱 | 有部分特征 | 一眼可辨且动作逻辑统一 |
| 运镜质量 | 无意义推拉／空绕 | 有变化但动机弱 | 物理路径清楚且与动作同步 |
| Shot 可读性 | 看不到脚步／动作被遮 | 大多数动作可见 | 重要动作与视觉重点完整呈现 |
| 转场价值 | 没有钩子或硬凑 | 可剪辑但不突出 | 有明确方向／形状／动作接点 |
| 整体商业感 | 像随机生成片段 | 有基本完成度 | 有明确导演意图和节奏设计 |

## 12.3 失败诊断流程

遇到错误先判断属于哪一层，不要所有问题都通过增加负面提示词解决：

1. **素材问题：**Picture 参考图职责冲突，或 Audio 1／manifest 错误。
2. **时间问题：**动作窗口过短、节拍位置计算错误、Global／Local 混淆。
3. **编舞问题：**动作没有入态／出态，主结果不明确，动链过载。
4. **摄影问题：**机位抽象、相机路径不可执行、运镜晚于动作、关键脚步被裁掉。
5. **连续性问题：**人物、服装、场景或道具没有锁定；跨段依赖模型自动继承。
6. **语言问题：**提示词中英夹杂、形容词太多、动作库编号泄漏、语义冲突。
7. **生成随机性：**在结构已正确时，才考虑简化措辞、降低同时执行的目标数量或再次生成。

## 12.4 症状—修复表

| 症状 | 先检查 | 优先修复 |
|---|---|---|
| 人物脸变胖／比例改变 | 是否重新描述外貌、是否用错误参考覆盖 | 精简外貌文本，强化 Picture 1 唯一身份权威 |
| 墙壁／背景颜色变化 | 环境权威是否明确，是否新增了场景描述 | 加强环境母图锁定；删掉不属于参考图的景物词 |
| 衣服自动多出外套／披肩 | 是否用形容词扩写服装、是否写了不必要衣物词 | 只保留源图服装，不增加外穿层 |
| 舞者原地摇晃 | 是否有明确脚步／移动路线／动作完成点 | 设计一条有方向与重心变化的完整链 |
| 一直交叉脚 | 交叉步是否有落点与打开步骤 | 交叉后完成承重交换，再明确打开／侧点 |
| 镜头一直很远 | 是否只写“wide dynamic cinematic” | 写明摄影机与人物的真实距离和贴近路径 |
| 镜头围着不动的人转 | 是否把 orbit 当成默认动态词 | 让相机平移跟步、贴身短弧线或在真实旋转时匹配相位 |
| 关键动作被特写遮挡 | Shot 景别是否正确 | 脚步／跳跃／旋转改用全身或中全身，特写缩短 |
| 动作已经做完镜头才推近 | 是否没有同步时间码 | 让相机在预备阶段跑位，动作启动时同步响应 |
| 古风动作像现代宅舞 | 是否没有定义持续层和主舞种 | 重写提沉、虚实重心、云手、穿掌和袖片逻辑 |
| 现代舞动作变成慢速摆拍 | 是否用过多“graceful／slow／elegant” | 加回 Groove、脚步、重拍与能量释放 |
| H3 出现额外人物 | Picture 2／3 是否含有其他人物，是否描述了“有人” | 声明参考人物仅用于镜头，不复制；锁定演员数量 |
| 手指出现畸形 | 手势是否太复杂、两手是否重叠 | 简化为一个稳定手势，缩短手部特写 |
| 段间动作断开 | 是否假设 H3 自动继承上段 | 在 MD 转场表中做剪辑匹配；本段自己建立入态 |

## 12.5 修订时的变更纪律

- 先保留已经正确的音乐、总时间、人物、服装和环境，再改发生问题的局部。
- 明确标注本版改动的段落和内容；没有改的段落可注明沿用来源版本，但交付的最终 MD 若要求可直接使用，仍应包含完整可复制正文。
- 不要为了修复一个手势而重写整段音乐时间线。
- 不要把一个镜头问题变成全片风格重做。
- 不要因为某次生成失败就加入几十条互相冲突的 Negative Prompt；优先简化动作和明确正向路径。
- 每次修改后重新核验总时长、段落边界、音频切片和相邻转场。

# 13. 常用英文 H3 摄影与动作语句库

这些是自然语言表达参考。实际项目应按图像与动作替换，不要不加判断地全部塞进每段。

## 13.1 物理机位句式

```text
The recording viewpoint comes from a real physical camera positioned just outside her right shoulder, close enough to preserve the foreground shoulder line while keeping her face readable.

A small camera is placed directly on the floor beside her feet, with the lens only a few centimeters above the ground and pointing upward along her body. The floor occupies the immediate foreground and her full figure rises naturally above the lens.

The camera is physically mounted directly above the performer. Its optical axis points vertically downward, perpendicular to the floor, creating a genuine top-down view rather than a diagonal high-angle shot.

The camera travels parallel to her lateral footwork, maintaining a consistent physical distance and keeping both feet and the full arm pathway in frame.

The camera moves along a short close arc from her front-right side toward her left-front side, following the same direction as her torso rotation without circling at a distance.
```

## 13.2 同步运镜句式

```text
The camera begins moving at the exact moment her supporting foot releases into the side step.

As her weight transfers onto the left foot, the camera trucks left at the same pace and keeps her center of mass framed.

The camera reaches the open-arm composition at the same instant her hands complete the extension on the musical accent.

As she absorbs the landing through both knees, the camera descends with her and settles at the end of the same recovery.

The camera is already in position before the main accent lands; the framing arrives first, then the movement reaches its peak inside the composition.
```

## 13.3 现代舞动作句式

```text
She transfers her weight onto the right forefoot, crosses the left foot behind, then opens laterally into a clean side press. Her pelvis follows the support change and her arms sweep from low center into opposing diagonals.

She maintains a compact knee bounce while alternating heel-toe pressure, then sends one continuous wave from the pelvis through the ribs, shoulders and wrists.

She pushes from the supporting forefoot into a small traveling skip, folds the opposite heel back, lands through a bent knee and immediately transfers weight to repeat on the other side.

She preloads through both knees, springs vertically with both feet clearly leaving the floor, opens her arms at the apex and lands softly with controlled knee absorption.
```

## 13.4 古风身韵句式

```text
Her weight settles into the supporting foot as the chest rounds on the exhale. On the inhale, the spine rises vertebra by vertebra, the head follows last and the gaze arrives at the lens.

She steps through a shallow curved cover step, lets the pelvis initiate a spiral, then sends the movement through the ribs, shoulder, elbow and wrist into a flowing cloud-arm pathway.

One palm threads beneath the opposite forearm and turns outward as the wrist completes the rotation. Her torso counterbalances the hand pathway while the supporting foot remains grounded.

Her arm initiates the sleeve sweep; the wide fabric follows with a slight delay, reaches its fullest arc on the accent, then settles naturally as her body completes the turn.
```

## 13.5 Shot 切换句式

```text
CUT on the completed landing, not during the unstable middle of the jump.

Use a match-on-action cut while the arm continues along the same diagonal path; preserve the motion direction but allow the camera position to change.

A brief foreground sleeve wipe fills the frame, then reveals the same established location from a new physical camera position.

Keep the detail insert brief, then cut back to a full-body view before the next footwork phrase begins.
```

## 13.6 动作完成与衔接句式

```text
Finish with her weight settled over the right foot, the left toe lightly touching the floor and the right hand gathered near her chest. This is a controlled moving end state, not a frozen final pose.

The released arm continues into the next phrase; she does not reset to a neutral standing position.

She absorbs the turn, stabilizes her supporting foot and lets the remaining fabric motion settle before beginning the next directional change.
```

# 14. 最终交付标准

一个合格的 H3 舞蹈 MV Prompt Pack 必须达到：

- [ ] 文件为一个完整 Markdown 文档，具备版本、素材、总方向、图片职责、时间索引、分段提示词、转场表和质量检查。
- [ ] 每一个 Segment 都有明确编号、Global 时间、Local 时长、Audio 1 文件、音乐定位和段间钩子。
- [ ] 每段提示词独立、自包含、可单独复制；不依赖“同上”或其他段落正文。
- [ ] 每段有明确舞种、持续层、具体动作链和身体动力学；不是姿势列表。
- [ ] 每个主要动作有进入、动力、峰值、惯性、回收与下一动作入口。
- [ ] 每个 Shot 有时间码、景别、物理机位、运动路径、动作触发和切出理由。
- [ ] 相机与身体共用时间轴；关键动作峰值与构图峰值同步。
- [ ] 关键脚步、重心、跳跃、转体和落地均有足够画面信息。
- [ ] 古风动作写出身韵和衣料惯性；现代动作写出 Groove、步伐、重音与身体隔离；融合风格有清楚主次。
- [ ] 图片职责和人物／环境／服装／道具锁定无冲突。
- [ ] H3 执行代码块为英文，Spoken 台词保留原文，内部动作库代号不泄漏。
- [ ] Audio 1 原声与实际切片时间准确；不擅自添加、重启或重制音乐。
- [ ] 段间转场有可剪辑的方向／形状／相位／遮挡钩子，但不依赖模型自动继承上一段。
- [ ] 生成后有分项审查和定向修订，不以“整体感觉不错”代替逐项验收。

# 15. 简明执行流程卡（每次新 MV 从这里开始）

1. **盘点素材：**拿到人物图、环境图、镜头参考图、音频、歌词／字幕、节拍 JSON、动作库。
2. **核对音频：**总长、BPM、Beat、Bar、Phrase、首个 downbeat、段落事件、切片边界。
3. **建立视觉圣经：**确认人物锁、场景锁、服装锁、道具账本、色彩、风格和禁区。
4. **确定 MV 方向：**纯舞蹈／舞蹈主导剧情／情绪肖像／群舞；明确主舞种。
5. **画能量曲线：**决定主歌、副歌、桥段、尾奏的舞蹈密度和镜头尺度。
6. **按音乐切段：**优先乐句与动作收点，单段控制在适合 H3 的时长范围。
7. **逐段编舞：**持续层＋主动作链＋微表情；写入态／出态，检查时间容量。
8. **逐段设计摄影：**物理机位＋路径＋Shot 时间码＋同步触发＋构图峰值＋恢复。
9. **设计剪辑：**每个镜头有动机，每个段间边界有单一主钩子。
10. **生成完整 MD：**中文制作说明＋英文独立 Prompt，全部段落完整列出。
11. **生成前审查：**通过第 12.1 节清单后再交付。
12. **生成后诊断：**按人物、场景、音乐、动作、运镜、剪辑逐项检查；只修正错误所在层。

> **最终导演原则：**一支专业 MV 的高级感不是动作名称多、镜头术语多、特效多，而是每个动作都有身体因果，每个镜头都有观看理由，每个重拍都有视觉兑现，每个片段都能独立生成，每段之间又能被剪辑成同一支完整作品。
