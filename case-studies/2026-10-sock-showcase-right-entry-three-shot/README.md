# Case Study 017 — 三种袜子 · 右入换装三镜流水线（Three-Sock Walk-In Reset · Three Shots）

> 一支 5.9 秒的服装展示流水线（9:16），**3 个服装状态 = 3 个独立镜头**：每个镜头都从画右**一大步跨进画面**（跨步中入画、第一帧已穿该状态新装），落定中心摆 pose，pose 保持中被**硬切**走——人物从不走出画框，跳切痕迹可见是设计的一部分。腿部袜饰三状态（光腿油光 → 菱格黑丝 → 蕾丝过膝），主服装/场景/机位全程锁死。**本案例最大教训："藏在步点里的画内换装"假设被逐帧证伪——真相是硬切 + 右入跨进。**

## Inputs（输入）

- **PICTURE 1**：唯一视觉权威——人物身份、脸、发型、体型、主服装（红色漆皮挂脖束身短裙）与全部配饰；提示词零外貌描写。
- **AUDIO 1**：原片音轨 1:1 复用（5.9s）；两个剪接点 2.267s / 4.233s 落在音频重拍上。
- 三个独立镜头的提示词全文（一镜一状态，三段分别生成）：[`prompt.md`](./prompt.md)。

## The problem（实际踩过的坑）

1. **"步点画内变装"误判**：0.1-0.2s 间隔抽帧看到腿部状态在跨步中突变，得出"换装藏在一次迈步里"——**漏掉了硬切**。同景同机位的换装硬切在 scene 0.27 阈值下完全隐身，0.08 才现形（2.267 / 4.233 / 4.4 三处）；逐帧复核后证伪原假设；
2. **"左出右进"过度设计**：为解决生成时的两人同框，设计了"走出清屏+空帧停留"——但原片人物**从不走出画框**，被切走的是 pose 中的她；左出右进是凭空发明的机制；
3. **一段生成承载多状态**：把三个状态写进一次生成 → 出现"上一个人没走完、下一个人已露半个"与"第三状态凭空出现"——违反一镜一状态铁律；
4. **文字标签默认渲染**：初版把源片的横幅+编号标签写死进提示词——按需可移除（无文字版=纯视觉状态切换，靠袜饰差异区分）。

## The breakthrough（写死的事）

### 1. 右入跨进 = 镜头开场

每个镜头的第一帧，人物**已经在跨步中**：一大步从画右跨进画面（单步跨入，非多步行走），运动模糊落在入画帧上；落定中心后 pose 保持到镜头结束。三个镜头的入画跨步读成"同一个人反复走进来"——但每双袜子不同。

### 2. 一镜一状态，装配=硬切

每个状态一段**独立生成任务**（一段生成永不承载两个状态）；状态间硬切由剪辑完成，提示词内不写 morph / in-shot swap / walk-out / empty frame。切点两侧都在迈步中，跳切痕迹故意保留——"有痕迹但读成连续的一步"正是目的。

### 3. 恒定项锁死引导视线

主服装（红漆皮束身裙）、场景（厨房）、机位（固定正面全身、零运镜）全程不变——**唯一变量（袜饰）**在镜头间切换，视线被结构本身引导。

### 4. 文字标签联动（可选）

顶部常驻横幅（全片主题）+ 左侧编号标签（与镜头一一对应，切镜瞬间换标签）为源片格式；H3 应用可整体移除文字，纯视觉区分状态；audio 直接铺底卡点，切点吸音频重拍。

### 5. 服装状态目录写法

每状态一条，含编号标签原文 + 变化项精确描述（材质/花纹/高度），不变项写一次：状态1「脆皮水」= 无袜、腿部涂油呈水光；状态2「菱格黑丝」= 黑色菱格纹连裤袜；状态3「蕾丝花边」= 红色蕾丝翻边过膝袜。

## 提交工作流

1. 三个镜头**各自独立生成**：附 **PICTURE 1** + **AUDIO 1 对应切片**（0-2.267 / 2.267-4.233 / 4.233-5.900）；
2. 按时间轴硬切拼接（跳切即设计）；AUDIO 1 整条 1:1 铺底，切点吸重拍；
3. 每段首帧人物都在跨步入画中——不存在"凭空出现"，也不存在"上一个人没走完"（每段只有一个人）。

## Anchor check（提交前逐条过）

- **anchor coverage**：每镜六锚齐备——单图锚、跨步入画开场（第一帧已在步中）、状态袜饰精确描述、pose phrase、单人居主声明、锁定机位声明；
- **continuity**：三镜头同景同机位同构图，只有袜饰变；入画方向全部从画右；
- **timing**：切点 2.267 / 4.233 与原片逐帧对位；audio 1:1；
- **physical causality**：跨步入画 = 一次真实迈步的物理过程，落定后膝软缓冲；
- **anti-copy distance**：不附源视频、不复用其人物/场景；只借"右入=新状态"的镜头结构。
