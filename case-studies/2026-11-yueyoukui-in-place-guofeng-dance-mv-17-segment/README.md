## 核心方法

### 1. 图 1 绝对锁定（零重写、零扩展）

与案例 025「图 1 锁人物+环境、不重写外貌」同源但更严：执行总纲把图 1 定义为**唯一且完整的视觉母参考**，提示词不重新描写或补充任何视觉属性；禁止模型根据文字重新设计人物或环境。所有段落都在同一张图定义的视觉世界内完成——只改变**人物动作、摄影机观察位置与剪辑视点**，不改变图 1 中的任何视觉设定。

### 2. 原地舞蹈硬约束（本案例的签名纪律）

- 全片**不走动、不沿屋脊行进、不向镜头逼近或远离、不横穿场景、不做舞台走位**；脚下只允许原地虚实步、点步、并步、盖步、轴心转身、重心交换、屈膝沉身、提踵和短距离脚掌调整。
- 「点步、盖步、并步、转身」只服务于原地舞句，不得被模型扩展成连续行走；每次脚步完成后重心回到原始表演区域。
- **舞蹈必须贯穿全片**：不能用长时间站立、看月、抬头、走路或空镜替代舞蹈；空镜只作短促剪辑呼吸，不切断动作链，切回人物时承接上一镜动作、不重新起势。
- 每段至少 **2 条**有明确动作结构的古风舞蹈链，较长段落 3–4 条；不把每拍拆成互不相关的小动作，也不只写「优雅舞动」。

### 3. 动链库直编（库 → 原地改造）

编舞不是动作名称罗列，每条链都写全：起始支撑与预载 → 动力从脚底/重心传至骨盆、胸腔、肩肘腕 → 主要动作峰值 → 惯性控制 → 制动回收 → 下一链入口。库中依赖扇、长绸、水袖、圆场碎步或行进路线的链**不取用**；取用的链全部改造为无道具、原地定点版本。动作难度服从时间窗容量——宁可减少数量，不压缩成模型无法执行的动作堆叠。

### 4. 三个 Hero 的容量纪律

| Hero | 落点 | 链族 | 展开要求 |
|---|---|---|---|
| 1 | SEG07 | 点步翻身 → 探海线（TURN + LINE） | 预载→动力传递→峰值→定点→制动→释放，完整全身呈现 |
| 2 | SEG13 | 单次 360° 掖腿转 → 开臂制动（TURN + ACCENT） | 同上；单圈不贪多 |
| 3 | SEG16 | Attitude / Arabesque 高位延展 → Hero Lock → 受控回收（LINE） | 延展-锁定-回收三段完整 |

Hero 动作不能被特写剪碎；不为「高级」加入空翻、连续多圈旋转、无支撑悬浮或高危地面技巧。全片旋转合计 2 次（点步翻身 + 掖腿转），符合库的旋转预算 ≤2 条纪律。

### 5. 歌词只做情绪、不做插画

歌词是抽象情绪语境，**绝不是分镜指令**：不因歌词名词新增道具、人物、动作或场景；表演者不唱、不对口型。

## 可复用经验

1. **原地重构法**：当参考图/场景本身是固定站位构图（屋顶、月台、窗前）时，把「人物走位」从提示词中整体移除并换成点步/盖步/并步/轴心转身词表，同时把「舞蹈必须贯穿」写成硬约束——能显著抑制 H3 用走路和空镜填充时长的默认倾向。
2. **库链改造三分法**：删（依赖道具/行进的链不取）、改（保留动力结构、替换支撑形式）、留（纯上肢身韵链直接调用）。
3. **图 1 信息的「零重写」边界**：总纲声明「提示词不再描写图 1 已有属性」之后，正文只出现动作、机位与时间——外貌词彻底绝迹，能同时抑制换装与背景漂移。
4. **空镜呼吸规则**：空镜只作短促剪辑呼吸且不切断动作链，切回人物必须承接上一镜动作——这是「舞蹈贯穿全片」与「允许剪辑节奏」两难的标准解。
