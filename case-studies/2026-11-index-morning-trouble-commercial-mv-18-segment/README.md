## Rev.8.7 的五个关键变化

1. **SEG06 舞蹈优先重建：** 原早餐桌静物／剧情镜头改为与 SEG05 同一套 178 BPM 商业 J-pop 表达——持续膝弹底层、交叉步、侧点回弹、后踢小跳、下沉起身身体波浪、横向 skater-hop 与短促斜向换面；摄影机与起势、重拍、落地同步。保留原 13.794 s 时长、四个演唱窗口与 SEG07 餐盘圆形匹配钩子。
2. **SEG06 加入裙内打底层：** 短款、贴身、与原服装同色系，穿在原裙内部，不形成外穿长裤轮廓；只在正常跳跃与裙摆惯性中自然可见，不使用窥视镜头。
3. **多来源合并 18 段：** SEG01 用被窝 POV 独立稿；SEG02–05、07–08 用 Rev.8.3；SEG06 用 Rev.8.7；SEG09–14 保留 Rev.8.4；SEG15–16 用跳跃版独立稿；SEG17–18 用 Rev.8.6 动作链恢复版。
4. **魔法书脑内化：** 魔法书属于脑内设定而非现实道具，全片删除实体书、书页、翻书与书架，改用眼神、触碰太阳穴与表情暗示。
5. **Spoken 结构化：** 四段对白固定 `<Subject 1> (S1)`，日语写入 `<d>[Japanese] ...</d>`；说话镜头用稳定正面面部近景，嘴唇无遮挡、手势在下巴以下，每段结束明确闭唇。
